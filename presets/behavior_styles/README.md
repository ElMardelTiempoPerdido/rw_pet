# 行为风格配置

本目录准备七个维度、每维度三套风格，共 21 套可编辑的组合。每套风格都完整写出所属维度的参数，当前共覆盖 140 个互不重复的字段

已接入设置 > 行为中的七个风格选择器，归在原有四个行为分组中。每个维度提供“显示高级参数”，默认隐藏详细列表，仍可展开编辑全部原有参数。下表是第一版风格调校，具体动作观感可以继续调整

## 文件用途

| 文件 | 用途 |
| --- | --- |
| `builtin.toml` | 内置风格的名称、说明、排序和完整参数；维护发行默认时编辑这里 |
| `local.toml` | 可选的本地覆盖与新增条目；当前为空，仅附注释示例；已加入 Git 忽略规则 |

发行目录包含内置表和本说明，EXE 内也带有内置表供单独运行时使用；不会打包用户的 `local.toml`。缺少本地文件表示没有覆盖，不生成或分发同名空文件；覆盖升级不会清除用户自己添加的内容

## 维度与风格

| 维度 ID | 名称 | 三套风格 | 参数数 |
| --- | --- | --- | --- |
| `daily_activity` | 日常活动 | 静静停留 / 适度活动 / 经常走动 | 17 |
| `drift` | 漫游节奏 | 偶尔漂浮 / 走走停停 / 连续漂浮 | 27 |
| `mouse_attention` | 鼠标关注 | 偶尔留意 / 适度关注 / 好奇注视 | 7 |
| `mouse_avoidance` | 鼠标躲避 | 不躲不闪 / 轻轻避让 / 保持距离 | 25 |
| `drag_reactions` | 拖动反应 | 安静回应 / 偶尔抗议 / 活跃扑腾 | 38 |
| `reading_habits` | 阅读习惯 | 偶尔查看 / 从容阅读 / 专注研究 | 18 |
| `pearl_interaction` | 珍珠互动方式 | 召到身边 / 走近查看 / 绕珠观察 | 8 |

“适度活动”“走走停停”“适度关注”沿用目前代码默认值，其余按确认的表现方向设置。三套阅读风格均保留 50% 的矩阵珠选择比例；三套珍珠互动方式保留相同的矩阵避让半径，主要通过观察权重、距离和跟随范围形成区别

不躲不闪仅关闭躲避开关，仍写全一套轻柔的躲避参数，便于以后手动开启。所有拖动风格都保留随机反应和手臂物理限位，活跃扑腾也不会每次都发声或展示投影

## 改名、调值与新增

条目沿用 `[[styles]]` 与 `[styles.values]` 结构：

```toml
format_version = 1

[[styles]]
id = "mouse_attention.curious"
dimension = "mouse_attention"
order = 30
name_zh = "好奇注视"
name_en = "Curious gaze"
description_zh = "较远处的鼠标也容易引起注意，等待较短，更常转头跟随"
description_en = "Readily notices the cursor from farther away and follows it after a shorter wait"

[styles.values]
"interaction.hover_radius" = 220.0
"interaction.hover_dwell_seconds" = 0.8
"interaction.hover_probability" = 0.85
"interaction.hover_open_probability" = 0.35
"interaction.petting_enabled" = true
"interaction.petting_seconds" = 1.5
"interaction.petting_grace_seconds" = 0.6
```

- **改名**：修改 `name_zh` / `name_en`，保留 `id`；说明文字分别修改 `description_zh` / `description_en`
- **调值**：修改 `values` 中对应字段；风格库使用完整路径，带点的键必须保留引号，不能写成 TOML 的嵌套键
- **新增**：复制同维度的完整条目，改成新的 `id`，修改名称与参数；同一文件内 ID 不得重复
- **排序**：`order` 只控制同一维度内的顺序，现有值为 10、20、30，新增条目可以插入 15、25 等位置
- **本地覆盖**：同 ID 的本地条目仅填写想覆盖的元数据或参数，未填写项继承内置条目；`dimension` 不能更换。本地新 ID 必须有完整参数，不继承当前角色的值
- **文件格式**：保留 `format_version = 1`，这表示文件格式版本，调值或新增风格时无需修改；请使用 UTF-8 保存

内置表刻意不使用参数继承或当前角色默认值，选中某套组合后的结果不会受到之前选择过哪个风格的影响。加载器会先合并本地覆盖，再做完整性、类型与取值校验。坏条目跳过，其余有效条目仍可使用；坏的本地覆盖不会抹掉对应内置风格。选择器提示中可查看加载错误

兼容摸摸加入前的鼠标关注风格：保留原四项数值，仅为缺失的三个摸摸字段补入上述默认值；已填写的摸摸字段不覆盖，缺失旧字段或含未知字段仍报错。三套内置关注风格暂时使用相同的摸摸配置，满足条件后固定触发，没有概率参数

## 单位与归属边界

- 概率和手势幅度使用 `0～1`，例如 `0.35` 表示 35%；选择权重按相对大小比较，不要求相加为 100
- 时间单位为秒，运动仍按 40 Hz 推进；距离为逻辑像素，不随系统缩放改变含义
- `float_speed`、`drift_speed`、`base_speed` 和躲避的 `speed_min/max` 沿用现有逻辑像素/帧单位；`gesture_speed`、`speed_min/max_factor` 为倍率
- 普通移动和漫游共用的跨边参数只归日常活动，不写入漫游风格
- 读珠触发、间隔、时长、睁眼和选珠比例归阅读习惯；观察方式权重、距离、矩阵避让与跟随范围归珍珠互动方式
- 语音来源、音量、珍珠数量、投影透明度、光环、屏幕活动区以及本机移动/拖动许可不由本库覆盖
- 鼠标躲避仍依赖先成功关注鼠标；矩阵珠始终召近，固定珠才按方式权重选择动作；关闭移动或找不到路线时仍按已有规则召近或归位
- 摸摸独立于普通关注概率和本机拖动许可；只接管头眼，识别到持续摸动后暂缓鼠标躲避，结束后重新计时

字段含义和时间范围另见[拖动与珍珠互动参数](../../docs/oracle/behavior-parameters.md)、[已有日常活动与漫游参数](../../docs/preset-field-scopes.md)

## 选择、保存与旧配置

风格用于一次性填入本维度参数，角色仍保存完整的实际值。改动风格定义不会自动修改已保存的角色；重新选择该风格才应用新参数

改名不改 ID；应用时由程序记录定义版本。手动调整任一所属参数后，该维度显示为自定义，不根据数值重新匹配。导入角色时即使找不到对应风格，也保留完整参数并显示自定义

- 选择器填入当前角色草稿，沿用角色自动保存或手动保存的既有设置；关闭自动保存时可取消未保存修改
- 每个维度的标记保存在角色 `config.oracle.behavior_styles.<维度>` 下，包含 `id` 与 `version`；空字符串表示自定义
- `version` 为 `v1:` 加参数内容的 SHA-256，不是文件格式的 `format_version`；改名、改说明或排序不改变参数版本
- 定义更新后，旧角色保留原参数和所选版本，界面给出提示；重新激活同一项也会应用新定义
- 手动编辑或单项恢复任一参数，只清除所属维度的标记；改回相同数值仍是自定义
- 完整恢复角色默认值会一并恢复其原始风格标记；恢复行为页程序默认值则显示自定义
- “显示高级参数”与四个外层分组折叠都只影响展示，不更改参数、风格、资源禁用状态或保存状态；本窗口关闭后不记忆展开状态
- 旧设置、旧角色和旧分享包没有标记时使用自定义，既不匹配风格，也不改写已有行为数值
- 分享包携带全部实际参数和来源标记；接收端缺少对应风格时显示自定义，数值与原始来源标记仍保留
- 修改 `builtin.toml` 或 `local.toml` 后重新打开设置窗口读取，不需要重新启动桌宠

语音来源仍单独显示，不属于任一风格；选择行为风格不会开启本机自主移动、鼠标拖动或语音总开关，也不会解除资源或角色能力限制
