# 完整预设与外观引用

**设置 → 预设** 提供完整预设的选择、导入、导出和目录入口；**设置 → 外观** 继续管理独立外观

完整预设由行为参数和一份随包携带的外观组成，适合分享同一角色的外观及个性表现

## 导出、分享和载入

1. 在各设置页调整角色行为，在“外观”页选择或编辑外观
2. 在“预设”页点击“导出完整预设…”，填写名称；可以在这里查看外观来源，或跳转到外观页继续调整
3. 分享生成的整个文件夹，可先将它压缩；不能只分享 `profile.json`
4. 接收者解压后，点击“导入完整预设…”选择其中的 `profile.json`；也可以将整个文件夹放进 `presets/profiles`，刷新后下拉选择
5. 载入后参数先进入设置草稿，允许继续微调；点击“保存并应用”或“保存并关闭”后才影响运行中的人偶

导出读取当前草稿，包含尚未保存的外观和行为调整，不要求先保存其他页签或填写有效的游戏目录。取消设置不会应用本次载入，但已导入或导出的文件夹会保留

默认存放位置：打包版为 EXE 同级的 `presets/profiles`，源码版为工程根目录的 `presets/profiles`；不受启动工作目录影响，也不会写入单文件 EXE 的临时解压目录

```text
BellPet.exe
presets/
  appearances/                       # 独立外观库
  profiles/
    profile-角色名-唯一目录后缀/
      profile.json
      appearance/
        appearance.json
        images/
          图片内容摘要.png
```

没有 PNG 引用时，不生成 `images` 目录

## 参数范围

以 [字段归属登记](preset-field-scopes.md) 为准，完整预设导出全部 34 个 `profile` 字段，外观副本导出当前主体对应的 `appearance` 分支

- 行为包括鼠标观察与避让、拖动反应概率、漂浮和漫游速度、跨边与漫游概率、珍珠数量与行为、投影不透明度、光环大小及电弧数量等
- 尚未在 GUI 展示的参数同样保留，例如底座速度、珍珠跟随范围和部分拖动反应概率；导入后保存、重新打开设置和再次导出均不会丢失
- 控件显示的小数位数不影响未编辑参数的存储精度
- 本机字段保持不变，包括游戏目录、语言、屏幕与边缘限制、缩放、机械臂缩放、音量、自主行动和拖动总开关、线缆隐藏、外发光、光环/电弧显示开关及监视者设置
- 切换当前主体时，只更新它对应的外观分支；另一主体的配色和形态参数保留。附加外观与珍珠播放光晕颜色仍按现有规则作为共享外观字段载入

同版本文件缺失的行为字段使用代码定义的默认值补齐，不继承上一份角色参数或本机修改过的默认 TOML；未知字段、非行为字段、非法数值和不支持的格式版本会被拒绝

## 外观引用

`profile.json` 中的 `appearance` 同时记录外观 ID 和包内相对路径

```json
{
  "id": "外观的 UUID",
  "path": "appearance/appearance.json"
}
```

载入时始终读取这条路径指向的副本，并验证 ID 一致；不会到独立外观库寻找或替换成同 ID 的新版。因此，作者分享完整预设时的外观能随行为一起复现

- 从独立外观或另一份完整预设开始编辑时，导出副本保留外观 ID 和名称，但内容来自当前草稿，包含本次修改
- 没有外观来源时，导出自动创建新的外观 ID，并使用完整预设名称
- 在载入完整预设之后另选独立外观，行为参数保持不变，之后导出会引用新选择的外观副本
- 包内外观或 PNG 缺失、引用 ID 不一致时，整个预设载入失败，当前草稿保留；不会悄悄使用其他外观
- 载入时 PNG 复制到用户配置目录的 `appearance/images` 缓存；成功保存后删除分享目录也不影响当前外观

当前生效的参数独立保存到用户配置，不在启动时自动跟随共享文件更新；重新打开设置时显示“当前配置（不关联完整预设）”，已保存参数继续生效

## 重复版本

完整预设和独立外观各自按 ID 管理重复项，规则一致：

- 同一 ID 使用 `updated_at` 最新的有效版本；文件系统修改日期不参与排序
- 日期相同时按路径稳定选择；无效新版本不会覆盖有效旧版本
- 小红字显示重复项路径，当前采用的版本列在第一项；无效文件另行提示
- 选择一份完整预设后再次导出，保留完整预设 ID，生成新日期和新目录，不覆盖旧目录
- 要独立另存，可先选择“当前配置（不关联完整预设）”，参数不变，下一次导出使用新完整预设 ID；它仍可引用相同外观

## 格式与代码

`profile.json` 使用 UTF-8 JSON，顶层字段：

| 字段 | 含义 |
| --- | --- |
| `type` | `rw-creature-pet.profile` |
| `version` | 格式版本，当前为 `1` |
| `id` | 完整预设 UUID，与外观 ID 独立 |
| `name` | 1～80 字符名称 |
| `updated_at` | 含时区的 ISO 时间戳，导出时为 UTC |
| `config` | 原配置嵌套结构，仅包含 `profile` 行为字段 |
| `appearance` | 外观 ID 与包内相对路径 |

包内的 `appearance.json` 沿用 [外观预设格式](appearance-presets.md)，可单独通过外观页导入。资源引用不允许绝对路径、父目录跳转或链接逃逸

写入时先在暂存目录准备全部文件，验证成功后整体改名；失败不会留下能被下拉框误选的半成品

- `presets/profile.py`：完整预设格式、范围校验、缺省值和配置合并
- `presets/profile_library.py`：完整预设导入导出与外观副本
- `presets/common.py`：两类预设共用的元数据、字段操作、路径检查、目录扫描与发布
- `oracle/ui/preset_panel.py`：两类预设共用的选择与文件操作
- `oracle/ui/profile_presets.py`：完整预设入口及外观来源提示
- `oracle/ui/settings.py`：草稿填入、预览和统一保存
