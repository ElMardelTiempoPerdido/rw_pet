# 自定义迭代器斗篷

在“设置 → 外观细节”的自定义参数中启用斗篷，默认关闭

- 单个槽位，单色主体，可调整自然下垂长度，范围为 8～48 逻辑像素
- 领口独立于衣袍，可选弧形或 V 型，调整宽度、深度、起始高度、弧形圆润度或 V 型尖端圆角
- 底边彩边可开关并调整颜色、宽度和内缩距离，距离 0 为包边
- 所有参数位于 `oracle.custom_appearance.cape`，随当前角色自动保存，支持参数恢复、外观及角色设置导入导出；Bell 不读取此槽位

## 首版轮廓

上半部沿当前袖子的外侧轮廓展开，自然下垂时，在袖子最宽处附近转为较直的侧边，底边使用较浅的圆弧

手臂开始抬起时，两侧轮廓快速向袖子外缘横向收拢，纵向收短分别跟随同侧手臂。单侧抬手时，未抬手侧只传递约 25% 的上提，保留更多垂坠长度，惯性参考点也使用相同规则。双侧同幅抬手时仍保持原有收短程度，底弧加深；长度越长，抬手时收短的绝对距离越大。最低点仍接近自然下垂高度，单侧抬手时偏向抬起较少的一侧。连接位置使用连续插值，避免最大宽度点换到下一段袖子时发生突变

在姿态轮廓上叠加轻量惯性回摆：起步时下摆稍有滞后，停止、转身和抬放手臂后回摆衰减。长斗篷响应更慢、摆幅更大，肩部和领口保持固定，手臂撑起时两侧收紧，仅底弧保留较明显的自由摆动

惯性使用三个响应点，在固定 40 Hz 物理步中更新，绘制只读取插值结果，不反向影响导航。微小余震归零后进入原有外观休眠；没有持续随机力、独立碰撞或整片布料网格。位置重置、长度改变和重新启用时清除旧惯性。倒立时不会另外强制回到世界竖直方向

## 绘制顺序与约束

从后向前：衣袍 → 袖子和手掌 → `after_sleeves` 附加部件 → 斗篷 → `after_cape` 附加部件 → 项链 → 最前层

斗篷领口只裁剪斗篷自身，开口中展示此前画好的衣袍、内搭或皮肤；不重画下层颜色，也不受衣袍领口反向裁剪。底边彩边限定在斗篷可见轮廓内

斗篷进入身体绘制缓存、像素化、外发光和鼠标轮廓。只平移或停稳时复用已有绘制指令，改长度、颜色等外观参数会刷新缓存。斗篷回摆单独刷新其绘制指令，不因此重建衣袍和袖子网格。绘制范围为长斗篷留出旋转及回摆余量，3×／4× 沿用已有粗像素规则

## 开发入口与预览

- `oracle/cape_config.py`：配置与范围校验
- `oracle/graphics/cape.py`：袖缘绑定、下摆圆弧、独立领口和彩边
- `oracle/motion/cape.py`：起停/转身/抬手惯性、摆幅限制和收敛
- `oracle/ui/cape_settings.py`：设置参数组
- `tools/oracle/review_cape.py`：输出短款／长款 × 垂手／双臂抬起／单臂抬起的六姿态预览至 `artifacts/cape/static-poses.png`
- `tools/oracle/review_cape_motion.py`：输出短款／长款的起停、转身、单侧抬手动态预览至 `artifacts/cape/inertia.gif`
- `tools/oracle/review_cape_settings.py`：使用临时角色库检查中英文设置界面
