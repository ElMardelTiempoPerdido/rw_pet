# 自定义衣袍领口

入口：设置 > 外观 > 自定义迭代器。保存并应用后生效，切换回手势之铃使用 Bell 原有领口；两套配色和尺寸分别保留

参数位于 `config.toml` 的 `[oracle.custom_appearance]`，除圆润度外均为逻辑像素

| 参数 | 含义 |
| --- | --- |
| `neckline_shape` | `arc` 弧形或 `v` 型 |
| `neckline_width` | 开口完整宽度，2～18 |
| `neckline_depth` | 从起始高度向下测量的深度，0～16 |
| `neckline_height` | 相对胸部中心的起始高度，-6～8；正值向头部、负值向下摆；独立于宽度 |
| `neckline_roundness` | 弧形圆润度，0～1；0 接近直线 V 形，增大后更接近 U 形 |
| `neckline_tip_radius` | V 型尖端圆角，0～4；0 为尖角，增大会削平最底部尖端，实际圆角受两侧长度限制 |
| `neckline_trim_enabled` | 显示单色领边装饰 |
| `neckline_trim_width` | 领边宽度，0～6；0 不绘制 |
| `neckline_trim_gap` | 从真实开口边缘到装饰的空隙，0～6；0 为包边，大于 0 为襟线 |

颜色使用 `[oracle.custom_colors].collar_trim`，上方配色区与领口区域的颜色按钮同步编辑同一个值。关闭装饰或切换形状不会丢失暂时未使用的参数

尺寸以未摆动的衣料为基准。领口及领边映射到现有布料网格，随旋转、摆动和褶皱变形；领边裁切于衣袍和袖根范围，不增加肩部轮廓。间隔沿开口法线测量，衣料变形后随之伸缩。极宽或极深的配置会被现有衣料外轮廓截断

衣袍长度仍表示衣料顶端到下摆的基准长度，修改领口深度不会缩短衣袍。领口上方可露出内搭或皮肤，取决于内搭开关

宽领口与袖根重叠时，挖去的袖子区域同时填充肤色；启用内搭后使用内搭颜色。填充沿用同一份随衣袍变形的领口遮罩，并限定于实际袖子轮廓，避免两侧漏出背景或被袖根截成窄领口；领边仍按原有层级覆盖开口外缘

领口设得高于衣袍上缘时，在指定领口宽度以内，凸出衣袍上缘的袖根也显示为肤色或内搭色，避免颈根两侧留下袖色小三角。此补充裁剪随衣料上缘变形，不改变原有领口深度、领边位置或领口宽度以外的袖子

运行 `python tools/oracle/review_custom_neckline.py --wide-shoulders` 可对照宽度 12／18 的弧领口、内搭开关，以及不同缩放和旋转姿态

运行 `python tools/oracle/review_custom_neckline.py --high-neckline` 可检查高位领口下，袖根超出衣袍上缘的部分是否仍保留衣料颜色

领口绑定只在配置变化时计算，后续帧复用三角形权重；停稳后沿用现有身体缓存，不新增物理模拟或定时器
