# 鼠标互动与珍珠互动参数

入口为 **设置 > 行为 > 拖动反应 / 珍珠互动**，新增字段分别位于 `[oracle.drag_reactions]` 和 `[oracle.reading]`

这些都是角色行为参数，随角色自动保存、导入和“导出分享此角色”一起处理；旧角色没有填写的新字段使用默认值，不覆盖旧字段的自行修改

可通过风格组合快速选择行动表现；勾选所属维度的“显示高级参数”后可调整下表中的全部参数

## 摸摸人偶

入口为 **设置 > 行为 > 鼠标关注 > 显示详细参数**，字段位于 `[interaction]`，随角色保存和分享

| 字段 | 默认值 | 作用 |
| --- | --- | --- |
| `petting_enabled` | `true` | 允许摸摸反应，独立于拖动开关与普通鼠标关注概率 |
| `petting_seconds` | 1.5 | 在实体轮廓内持续移动鼠标的累计触发时间，范围 0.1～60 秒 |
| `petting_grace_seconds` | 0.6 | 短暂越界或停止移动的容忍时间，范围 0～10 秒 |

无需按下鼠标。在实际人偶轮廓内持续移动达到阈值后，固定低头并闭眼，没有触发概率；无眼睛的角色只低头。机械臂、线缆、珍珠和光环不算摸摸区域，透明空隙不累计时间

摸摸专用的完整闭眼过渡约为 0.8 秒，由代码常量 `OracleEyes.PETTING_CLOSE_TICKS` 控制，暂不开放为用户参数；其他情况下的闭眼仍为 0.2 秒，睁眼速度也保持不变

摸摸过渡时，眼睛在相邻像素高度之间按覆盖率混合，让 1 倍显示下的 2px 眼睛也能逐渐收起；共有像素保持实色，完全睁开和闭合仍为原来的硬像素轮廓。普通睁闭眼不使用此混合，头部其他部件也不增加平滑处理

短暂中断期间暂停累计，并保留已有进度或低头状态；在容忍时间内继续摸动可以续接，超时后结束并重新累计。指针移动使用短时间窗口过滤静止抖动，人偶经过静止鼠标、调试窗口改变缩放都不计作摸动

摸摸反馈正式触发后（含短暂中断容忍期），不再选择新的自主移动、漫游、冥想或读珠行动。已经开始的移动、跨边、读珠及归位继续完成；漫游当前曲线继续走到终点，但不续接新路线、不插入跨边或读珠，总漫游计时与到期回正照常推进。完成当前行动后先停留，摸摸结束再恢复正常调度，不改动自主行动开关，也不拦截手动调试指令

头眼姿态由摸摸临时接管，抬头恢复时回到当前任务的朝向，常睁眼角色也会恢复原配置。开始累计有效摸动后，暂缓普通鼠标注视与躲避，并让已有侧倾自然收回；结束后重新等待普通注视，不沿用旧躲避计时

按下鼠标、拖动与拖动后归位优先，暂停、切换角色、重建场景或关闭摸摸都会清除进度，不排队补发。关闭拖动后仍通过透明窗口外的指针采样识别摸摸，不增加点击拦截区域

旧角色只为缺失字段使用默认值，已有参数和风格标记不变；手动修改任一摸摸参数将“鼠标关注”标为自定义，关闭“显示详细参数”不改变数值

2026-10-30 摸摸专项与相关回归共 151 项通过，日志为 `artifacts/petting-regression.log`。覆盖移动识别、短暂中断、按键/拖动取消、任务共存、常睁眼临时闭眼、缩放/DPI、关闭拖动后识别、旧配置和保存分享。另有中英文设置页独立离屏复核，证据位于 `artifacts/petting-review/`；尚未进行真实桌面鼠标体验验收或重打包 EXE

## 拖动动作

下表时间单位为秒，最短和最长允许相等；动作仍按 40 Hz 推进，实际时机按仿真帧取整，暂停不计时

| 字段 | 默认值 | 作用 |
| --- | --- | --- |
| `gesture_delay_min/max_seconds` | 0.15～1.5 | 抓起后第一次手势尝试的等待 |
| `gesture_interval_min/max_seconds` | 0.45～1.35 | 一组手势结束后，或抽签未触发后，等待下一次尝试 |
| `gesture_duration_min/max_seconds` | 1.4～2.6 | 每组手势持续时间，包含平滑起落 |
| `gesture_speed` | 1 | 三种手势的速度倍率，允许 0.25～3 |
| `gesture_min/max_amplitude` | 0.25～1 | 在安全扇形内选择抬手幅度，偏向小幅度；两手保留轻微差异 |
| `flutter_sync_probability` | 0.35 | 随机扑腾中同起同落的倾向，不改变固定交替动作的选择比例 |
| `eye_delay_min/max_seconds` | 0～0 | 首次睁眼尝试的延迟 |
| `eye_interval_min/max_seconds` | 0.9～2 | 睁眼保持结束后或未抽中后，再次尝试的等待 |
| `eye_duration_min/max_seconds` | 1.5～3 | 睁眼成功后的保持时间 |
| `voice_delay_min/max_seconds` | 0～3 | 首次语音尝试的延迟 |
| `voice_interval_min/max_seconds` | 1.8～3.8 | 按本次语音片段时长加此等待，安排下一次尝试；未抽中时只等待 |
| `projection_delay_min/max_seconds` | 0.15～1.5 | 抓起后投影自己的首次等待，只累计双手空闲时间 |
| `projection_interval_min/max_seconds` | 0.45～1.35 | 两次投影尝试的空闲等待 |
| `projection_duration_min/max_seconds` | 8.25～8.25 | 本次投影显示时间 |
| `projection_frame_seconds` | 0.375 | 两张扫描图交替的间隔 |
| `projection_lift_delay_seconds` | 0.35 | 投影显示后抬手指图的延迟，超过显示时长则不抬手 |
| `projection_move_min/max_seconds` | 0.65～1.6 | 投影小幅挪动的间隔 |

既有触发概率、单手/双手选择、交替动作占比与投影冷却继续使用原路径；投影的概率和冷却仍为 `oracle.drag_projection_probability`、`oracle.drag_projection_cooldown_seconds`

- 手势、眼睛、语音、投影有各自的等待和随机流，调快手势不会加快语音或睁眼
- 投影与摆手共享手臂，仍只能在摆手与收势结束后开始，不会同时争抢双手
- 松手、取消、停用反应时清除待触发事件和语音请求，不补播；正常松手允许现有手势平滑放下
- 手臂的肩外扇形、长度、驱动力上限不开放为风格参数，速度与幅度调高也不能绕过这些约束
- 语音和投影资源缺失时，仅相应参数不可用；禁用状态不清空用户值

## 珍珠互动

| 字段 | 默认值 | 作用 |
| --- | --- | --- |
| `start_probability` | 0.25 | 普通停留后读珠的概率，沿用既有参数 |
| `interval_min/max_seconds` | 0～0 | 一轮正常阅读的珍珠归位后，下一次自主阅读前的最小等待；到期仍须等行为选择 |
| `drift_probability` | 1 | 漫游期间每次读珠尝试的概率；0 时不为读珠中断连续路线 |
| `drift_delay_min/max_seconds` | 12～24 | 进入漫游后第一次读珠尝试前的等待 |
| `drift_interval_min/max_seconds` | 20～40 | 漫游期间一轮阅读结束或未抽中阅读后的等待 |
| `avoidance_probability` | 0.35 | 躲避鼠标的侧倾停稳后，选择原地读珠的概率 |
| `notice_min/max_seconds` | 0.9～1.5 | 注意到珠子后、接近或召近之前的准备时间 |
| `observe_min/max_seconds` | 40～60 | 人偶与珠子到位后的普通阅读时间 |
| `playback_min/max_seconds` | 90～120 | 矩阵珠触发播放动画后替代普通阅读的时间，不播放音频 |
| `eye_open_probability` | 0.1 | 每轮阅读只抽一次，不改变拖动、窗口和鼠标观察的睁眼概率 |
| `matrix_probability` | 0.5 | 同时存在矩阵珠和固定珠时，选择矩阵珠的比例 |
| `approach_weight / recall_weight / orbit_weight` | 35 / 35 / 30 | 固定珠的靠近、召近与局部绕珠观察权重，至少一项大于 0 |
| `observe_distance` | 50 | 靠近/绕珠观察的期望距离，允许 32～150 逻辑像素 |
| `recall_distance` | 38 | 召近阅读的期望距离，允许 30～150 逻辑像素 |

普通、漫游和侧倾停稳后的自主阅读共用读珠间隔；手动观察可以立即执行，中断阅读后也会安排间隔

矩阵珠始终抽取一颗召近，归位保留原槽位、颜色和字形；只有矩阵珠或只有固定珠时，自动使用存在的种类，不因比例设为 0 或 1 而失去所有目标；环绕珠和卫星珠不进入此选珠池

固定珠才按观察方式权重选择动作；关闭自主移动时仍可原地召珠，靠近路线不可行时也退回召近。距离是期望值，活动带、机械臂与身体避让优先；找不到安全的阅读点会结束本轮并送回，不能为了满足配置穿过禁区

## 风格选择与高级参数

设置 > 行为沿用四个分组，提供日常活动、漫游节奏、鼠标关注、鼠标躲避、拖动动作、阅读习惯、珍珠互动方式七个选择器

每个维度可以选择风格，也可以开启“显示高级参数”手动调整。开关只管理展示，全部原有字段仍然可用；手动修改即将所属维度标为自定义，不做数值反向匹配

选择结果和参数版本随角色保存与分享，旧配置不自动选择风格或覆盖数值。风格库后续改名或调值不会自动改动已保存角色，重新选择才应用更新

风格定义、字段归属与本地覆盖的维护说明见[行为风格配置](../../presets/behavior_styles/README.md)

### 范围参数的展示

行为页的 39 组最小值/最大值参数统一显示为一个名称和一个共同边框，例如“冥想时间：30.0 秒 至 60.0 秒”。左侧是最小值，右侧是最大值，分别支持输入和上下微调

七个维度展开详细参数后，使用与外观自定义一致的灰底包裹。普通数值和范围参数各占半行，相关的概率与等待、不同选项的时长或距离就近排列；拖动参数按手势、睁眼、语音、投影连续排列，不相关的项目不强行拼满一行

此调整仅改变展示，配置仍使用原来的两个字段；单位、精度、可选范围、风格标记、保存分享及校验保持原规则。右键任一端可单独恢复该字段默认值，滚轮仍滚动页面；折叠或切换语言不改变参数

“躲避进入距离/退出距离”“靠近观察距离/召近阅读距离”等含义不同的参数继续分开显示。资源缺失时，共同名称只标注一次“不可用”，两端分别沿用原有禁用条件

### 选项比例滑条

以下六组互斥选项使用分段滑条，下方等分显示名称和百分比，合计为 100%

| 所属维度 | 选项 |
|---|---|
| 日常活动 | 停留 / 冥想 / 移动 |
| 反重力漫游 | 普通连续漂浮 / 长段连续漂浮 |
| 反重力漫游 | 短暂停顿 / 普通停顿 / 长歇 |
| 拖动动作 | 单手划动 / 双手扑腾 / 双手交替 |
| 阅读频率 | 固定珠 / 矩阵珠 |
| 阅读行动方式 | 靠近观察 / 原地召近 / 绕珠观察 |

- 拖动分界线只交换相邻两项的份额，其他项保持不变，允许任一项为 0% 或 100%
- 手动修改某一项后，其余项按原比例分摊剩余份额；其余项原先均为 0 时平均分配。显示精度为 0.1%，舍入余数会补齐，总计保持 100%
- 旧权重只换算显示，打开、折叠、切换语言或保存其他参数不会重写该组。用户主动调整权重组后，整组保存为合计 100 的权重
- 原配置字段和风格文件格式保持不变，风格载入与恢复默认值按原数据读取。右键滑条或比例数值可恢复整组默认值，用户修改只将所属维度标为自定义
- 拖动手势的三项比例由原来的两层抽签换算：单手为 `1 - flutter_probability`，扑腾为 `flutter_probability * (1 - alternating_probability)`，交替为 `flutter_probability * alternating_probability`。编辑后反向保存，两手均为 0 时保留原来的双手内部偏好

滑条表示满足条件后的选择比例，不保证最终行动次数严格符合该比例。例如长歇通常不连续重复，矩阵珠始终召近，不能移动时固定珠也会改为召近。睁眼、语音、投影等独立触发反应不合并到同一条比例滑条；拖动表情仍保留启用项与独立权重设置

## 拖动表情

入口为 **设置 > 行为 > 拖动反应 > 拖动表情**，独立于上方“拖动动作”，直接展示全部参数，无风格选择或详细参数开关

配置保存于 `[oracle.drag_expressions]`，随角色保存、恢复与分享，不改写外观中配置的基础眼形

| 字段 | 默认值 | 说明 |
| --- | --- | --- |
| `probability` | `0.5` | 每次随机尝试触发表情的概率，面板显示为百分比 |
| `<眼形>.enabled` | `false` | 是否加入候选；旧角色与默认配置均不启用 |
| `<眼形>.weight` | `1` | 0～1000 的相对权重；0 不参与抽取 |
| `<眼形>.large_only` | `false` | 仅近期大幅拖动时加入候选 |

眼形标识：`squeezed`（`> <`）、`slant_in`（`\ /`）、`slant_out`（`/ \`）、`round`（`o o`）、`chevron_up`（`^ ^`）、`chevron_down`（`ˇ ˇ`）

- 拖动命中后首次等待 0.3～1.2 秒；后续尝试间隔 1.5～4 秒；成功后保持 2～5 秒，期间不重复抽取，结束后再开始下一次间隔
- 先筛选已启用、权重大于 0 且符合幅度限制的候选，再按概率触发并按权重抽取；没有候选时跳过本次尝试
- “大幅”按最近 0.6 秒鼠标逻辑坐标的范围达到 48 px 判定，资格短暂保留 1 秒；不依赖身体是否能跟上，也不累计整次抓取路程
- 松手时仅抽取一次 0～5 秒恢复期限，与自然结束时间取较早者，届时直接恢复；松手后不再开始新表情，不补播等待中的尝试
- 再次抓起撤销旧松手期限，但保留该表情剩余的自然时长；取消、关闭拖动、暂停、角色/场景重建或摸摸开始时立即清除
- 临时眼形覆盖双眼，各眼颜色和可见性不变，圆眼中心保持白色；恢复时显示用户配置的基础眼形及当时的睁闭状态
- 表情使用独立随机流，既不受“启用拖动动作”控制，也不会改变手势、睁眼、语音、投影或自主行为的随机节奏

时间与大幅判定常量暂位于 `oracle/interaction/drag_expressions.py`，不开放为设置参数。所有眼形未启用时，仅保留廉价的状态检查；静态表情不持续使渲染缓存失效
