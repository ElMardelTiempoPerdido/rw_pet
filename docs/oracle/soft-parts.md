# 自定义迭代器柔性部件 - 阶段 1～4

两个独立的柔性槽位，共用带状网格表现几何外形或分段变形的 PNG。默认关闭，仅自定义迭代器启用，Bell 不读取这两个槽位

## 正式设置与角色保存

选择自定义迭代器角色后，打开“设置 > 外观细节”，在耳机参数后可看到“启用柔性部件 1／2”。每组使用独立底色，尺寸、偏移、物理参数均采用双列排列；选择 PNG 后显示缩略图、文件名和导入／移除按钮

- 开关、几何外形、颜色、前后图层、固定点、位移、出发角度、宽度、长度、梯形末端比例、柔软程度、回摆衰减均可修改
- 沿用角色的自动保存开关；开启时合并连续修改并应用，关闭时使用“保存当前调整”，未保存的修改在关闭窗口或切换角色时丢弃
- 右键每个子参数可恢复当前角色提供的默认值；右键整组空白可恢复整个槽位。“恢复默认外观”和外观导入历史也包含这两个部件
- 两个槽位的参数和开关归各自角色保存，旧角色缺失的字段默认关闭，不继承上一角色。Bell 隐藏并忽略这两个槽位
- 图片导入前验证静态 PNG、尺寸和文件大小，成功后缓存副本；失败保留当前图片与参数。移除图片会同时关闭部件，避免自动保存不完整配置
- 通过“角色设置”中的导入／导出入口分享。外观文件携带两个槽位及引用的 PNG，完整角色设置携带其外观副本；关闭部件仍保留参数和图片。分享整个导出目录，不只分享 JSON
- 日常修改只保存当前角色的个人调整，不改写下载的外观／角色源文件；明确选择导出时更新已有文件，才会更新分享文件

PNG 按原始像素尺寸显示，1 图片像素对应 1 逻辑像素，随后随桌宠整体缩放；宽度和长度参数仅影响几何形状。选择 PNG 时隐藏这两项，切回几何形状会恢复显示并保留原来的值。物理链长度、绘制宽度及刷新范围均采用图片尺寸。所有部件继续保持鼠标穿透，不做碰撞

## 直接调试

```powershell
conda activate rw_pet
cd D:\CODES\PY\rw_creature_pet
python tools/oracle/debug_soft_parts.py
```

此入口临时启用两条不同颜色和长度的柔性带，隐藏线缆、光环与珍珠，并打开“柔性部件调试”面板。不会读写本机角色调整，也不会保存本次调试参数。加 `--geometry-only` 可不加载游戏图集；加 `--glow` 临时开启外发光，颜色、半径和透明度读取当前配置

普通 Oracle 调试窗口也新增了“柔性部件调试…”按钮，使用自定义迭代器配置时可调整

- 各槽位的显示开关、颜色、长度和完整宽度
- 外形：矩形、椭圆、梯形、三角形、圆端直线、PNG；梯形可调末端宽度比例
- 前后图层：后方位于人偶、机械臂和线缆下面，前方位于人偶及附加外观上面；同层时部件 2 在部件 1 上面
- 固定点：颈根、头部、腰部
- 本地 X/Y 偏移：正立正视时正 X 向画面右侧，正 Y 向脚；会随固定部位旋转
- 根部出发角度：0 沿人物向脚的方向，正值顺时针
- 柔软程度：越高越容易弯折
- 回摆衰减：越高越快停下

通过主调试窗口开启鼠标拖动、触发反重力漫游或停止移动，观察拖动惯性、倒立下垂、失重跟随和静止收敛。状态栏分别显示两个槽位的节点数量和运动/休眠状态；“重置部件姿态”只重置这两个部件

选择 PNG 后可导入本地静态贴图，宽高各为 1～128 像素，文件不超过 1 MB。PNG 保留原色和透明度，不乘几何颜色；调试窗口把副本存入临时目录，关闭本次调试进程后清理，不修改原图

PNG 的顶部中点接根部，底部接末端，图片原始高度决定物理链长度，透明留白也参与尺寸计算。左右方向以部件正立向下时为准，倒立或转动时随网格一起旋转，不自动翻面。分段共用顶点和纹理坐标，不按每段重复贴整张图片；同一网格的公共边不重复叠加半透明像素

矩形与圆端直线保持等宽，椭圆中间最宽，三角形由根部向末端收尖，梯形按末端宽度比例收窄。修改形状、PNG、颜色或层级时，若实际长度不变则保持物理姿态；更换不同高度的 PNG 时按新长度重建该部件的物理链

## 配置与行为

配置路径为 `[oracle.custom_appearance.soft_part_1]` 和 `[oracle.custom_appearance.soft_part_2]`，字段和默认值见根目录 `config.toml`

这些字段已登记为外观字段，随自定义外观及角色设置的读写、导出一起保存；PNG 副本一并携带，不依赖原始绝对路径。部件参数不在不同角色间借用上一角色的值。普通调试面板的即时调整仍只修改本次场景；需要持久保存时使用正式设置界面

每条带使用 5～16 个节点，前两个节点固定一小段根部，其余节点在 40 Hz 固定步长中模拟。继承人偶当前的重力比例，用单次前向投影保持各段长度，限制局部弯折，并独立休眠。部件不向人偶或机械臂施力；重置位置等大幅瞬移时整体搬移，避免拉成长线

## 像素化、外发光与桌面刷新

几何和 PNG 都在变形后按整个人偶的像素密度绘制：1×／1.5×／2× 使用相应精度，3× 放大 1× 像素，4× 默认放大 2× 像素；4× 的粗像素选项改为放大 1×。PNG 保留源图透明度，几何边缘不添加抗锯齿，放大时不做平滑插值。调试放大镜保持主视图的采样精度

附件复用全局外发光开关、颜色、半径和透明度，从变形后的实际 alpha 轮廓生成柔光，不对整个贴图矩形填充。柔光可平滑显示，绘制于实体下方；附件与人偶重叠时，不改变人偶原本的不透明颜色

两个附件的像素图和模糊图分别缓存。运动中的部件单独重绘，不重建已静止的身体缓存、另一附件的柔光或鼠标命中图；静止后复用结果。只修改发光透明度不重新模糊

局部重绘覆盖附件前后物理帧、完整宽度和外发光，并与上次绘制范围合并清屏。收回、缩窄、关闭、移除 PNG、切换角色及缩小发光范围都会清理旧像素；暂停时切换附件也即时生效

附件及其外发光始终保持鼠标穿透，不增加人偶的可拖动区域。附件允许伸出活动带；不增加导航约束，超出屏幕的部分由窗口自然裁切

## 本阶段边界

不做与其他部件、屏幕边缘或自身的碰撞，倒立时可以经过身体，较宽或较长的带可以折叠重叠。折叠处按从根到末端的顺序覆盖，末端显示在更上层
