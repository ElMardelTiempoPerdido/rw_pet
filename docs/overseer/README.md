# Overseer 桌面与调试场景（阶段 1–6）

在 Oracle 桌面和调试窗口中支持最多四只监视者：固定边缘根部、带惯性的头部、曲线身体、眼部透视和柔性触须（普通外观默认四条，可设为 3～5 条；朋友？固定两条），支持鼠标注视。
由手动操作启动一次预览，包含探出、观察、近距离缩回和原位重新探出。
支持随机出现和常驻两种方式，各槽位独立配色、注视和避让；缩回后可以在墙内换位

## 桌面使用

通过托盘的 **打开设置菜单 → 监视者**，勾选 **允许出现监视者** 后保存。可添加或移除最多 4 个槽位，为每个槽位选择主色、体型和普通外观的触须数量，并修改检查间隔、每次出现概率、持续时间/冷却时间的最短与最长值、鼠标与人偶各自的缩回/安全距离、缩回后换位概率。配置保存到既有用户设置，下次启动继续使用；默认仍关闭自动出现。

也可从托盘打开工具栏，点击 **触发监视者** 手动启动一次计时事件：跳过自动开关、概率和冷却，仍避开鼠标、人偶与四角。每次填入一个空闲的已配置槽位；所有槽位都被占用（包含避让隐藏及退场）或没有配置槽位时，按钮禁用。暂停、调试交接或工作区不可用时，按钮跟随工具栏一起禁用。没有安全位置时显示原因，不生成事件，也不影响人偶状态。

- 监视者使用人偶相同的主屏工作区、DPI 和 1×/1.5×/2× 物理像素倍率。直接读取全局鼠标位置；拖动开关、鼠标按键和人偶是否移动均不影响它。屏幕外的鼠标不作为注视目标，但靠近边缘时仍参与避让距离计算。
- 根部直接贴工作区的上/下/左/右边，不沿用机械臂轨道向内 18 逻辑像素的偏移；四角余量只约束沿边位置。有任务栏的一侧以任务栏外的工作区边界为准。调试场景使用相同边界，内部的圆角轨道线仍仅代表机械臂轨道。
- 每只监视者各使用一个独立、局部大小的透明置顶显示窗口，全部可见/透明像素都穿透输入，不设鼠标命中区域，不创建拖拽窗口，也不修改人偶的命中图。
- 工作区只改变屏幕原点时保留事件与剩余时长，移动显示层。世界尺寸改变或当前附着边被禁用时，撤掉旧事件；随机方式进入冷却，常驻方式重新寻找合法位置。保存体型变化时，对应个体重新计算沿边余量和悬停高度，再重新探出，保留事件剩余时间。屏幕暂不可用时隐藏并冻结，恢复后重新核对坐标。
- 托盘 **暂停桌宠** 同时冻结人偶和监视者，包括事件计时。只改监视者设置不会重建人偶、打断拖动/语音、唤醒衣袍/线缆或重绘人偶窗口。关闭自动出现会平滑退场；暂停时退场也暂停，恢复后继续。
- 打开调试窗口时，桌面隐藏并暂停，将同一组监视者模型和事件控制器交给调试窗口计时，使用相同世界尺寸。关闭调试后计时事件继续剩余时长，不再抽取一只新的监视者。无时限手动预览会被撤掉，临时参数恢复为桌面已保存配置；若期间工作区尺寸改变，也会清理失效的旧事件。

## 多槽位与出现方式

- **随机出现**：每个已配置槽位独立按检查间隔抽签，使用独立的持续时间、冷却和随机数；修改其他槽位不重置它的当前事件
- **常驻**：启动后在允许边缘随机选取安全位置，忽略出现概率、持续时间与冷却；避让仍可暂时缩回，并按原规则原位重现或换位
- 没有安全位置时，常驻槽位每秒重试一次，不挤入四角、人偶或其他监视者占用的位置；临时隐藏的监视者仍保留自己的槽位和位置
- 随机切为常驻时保留当前姿态；常驻切为随机时为在场监视者抽取本次剩余时长。关闭总开关会平滑退场
- 槽位编号固定为 1～4，新增槽位默认主色为白色 `#ffffff`，不覆盖已有配色；移除其中一只不会重新编号或重置其他监视者。所有槽位都移除时允许保存为空列表
- 调试面板可选择操作的槽位，其他槽位继续运行；没有配置槽位时仍能使用独立的临时预览，不带回桌面
- 每个槽位可选择 `appearance = 'standard'`（普通）或 `appearance = 'friend'`（朋友？），保存后在原位切换，不重置当前事件
- 每个槽位的 `size` 独立控制原版体型参数，范围 0.5～1，设置中以 0.05 步长调整；这是生物形态参数，不是整个桌面的绘制缩放。未编辑时保留配置中更细的精度
- `filament_count` 控制普通外观的触须数量，范围 3～5，默认 4。各条按数量均匀分布，沿用原柔性链和前后遮挡；朋友？固定两条，设置中隐藏数量控件，切回普通后恢复此前填写的数量
- 旧 TOML/JSON 槽位未填写 `size` 时继承顶层 `overseer.size`，保存后写入各槽位；新增槽位也从该值开始。缺省触须数量为 4，旧槽位身份、颜色和外观保留

## 朋友？外观

在 **设置 → 监视者 → 对应槽位** 选择 **朋友？** 并保存；调试面板中的 **外观预览** 只临时改变当前槽位

- 身体前段保持细长，扣除头部遮挡余量后，按 `PEAK_FRACTION` 到达最宽处，再于 `NECK_FRACTION` 收成细颈；根部保留最低显示宽度，因此离开根部时会先略微变细
- 主体前端延长，增加 6 个绘制采样段，额外长度基准为 8 逻辑像素；脸盘和观察光随末端前移，减少圆盘对细颈的遮挡，新增部分与身体一起探出和缩回
- 侧视时，根侧细长段向观察方向拱出，较宽的主体向另一侧回弯，形成 S 形中心线；弯身量带轻微滞后，固定观察时可以保持弯曲，换向时平滑经过中间姿态
- 花冠和观察光束使用独立的鼠标注视倾角曲线，身体位移、颈部和 S 形姿态保留单独的跟随响应
- 根段直接使用一条二次曲线，顺着弧线倾斜出墙，消除先垂直出墙造成的根部小反弧；与主体保持切线连续，根部和头部位置固定，头颈沿用原末端方向
- 短姿态和缩回过程会减弱弯幅，普通监视者继续使用原中心曲线
- 默认主色为黑色 `#000000`，用于身体、花瓣和触须主体色相；身体保留固定紫色 `#8859d6` 从根部渐变至主体色
- 固定浅黄色 `#E4E1CF` 圆盘替代眼球，不绘制原版瞳孔；花瓣贴图的所有非透明像素统一填充槽位主色，保留原透明度、曲面投影和遮挡。投影缓存包含颜色，多个不同配色的 friend 不会共用错误的花瓣颜色
- 两条触须共用脸盘后、颈部背向镜头一侧的连接点，基础配色为短须浅紫色 `#BDA3E7`、长须深紫色 `#8C46FF`；槽位主色有色相时，只替换基础配色的 HSL 色相，保留各自饱和度和明度，后段仍渐变至蓝色 `#0000FF`。黑、白、灰没有色相时沿用原紫色；触须调色使用有界缓存
- 双触须基准弧长为 24 / 36 逻辑像素，随体型乘以 `0.75 + 0.25 * size`，默认体型 0.6 对应 21.6 / 32.4，再按转头方向计算可见投影长度；复用普通监视者的五节点柔性链、弱牵引、自由末端和伸缩约束。两条都在身体和花冠后方绘制，随颈部移动和缩回，不增加额外计时器
- 连接点和展开方向共同参考垂直于颈部的背面方向，随左右转头连续投影，正视附近收向颈部背后，再从另一侧展开；C / S 弯曲偏好同步收窄、换向，实际链条仍保留惯性和边界约束。这是二维物理配合深度投影的近似，不是完整三维触须模拟
- 侧向投影增加非线性可见性增强，小幅侧视就能更明显地露出触须，中大角度逐渐趋近完整侧视，连接点、可见长度和弧线同步变化。正中仍保持零侧偏，连续换边，不强制保留某一侧，也不超过基准弧长
- 静止时短须有轻微 C 形、长须有轻微 S 形弯曲偏好：相对当前首尾连线弹性推动中段，并让自由末端分担反作用，不固定末端位置。弯曲随体型和伸缩比例缩放，移动惯性和工作区边界仍可改变实际形状
- 头部常驻微弱紫色柔光，直接沿用 `graphics/friend/body.py` 的 `ROOT_COLOR`（当前 `#8859d6`），不随槽位主色变化；与普通监视者相同，半径 11 逻辑像素、中心透明度最高 45/255，随探出程度淡入淡出。柔光位于身体及花冠下层，复用现有局部画布和绘制缓存
- 花瓣使用 `rw_creature_pet/skin/friend/friend_head_2x.png`，28×28 的 2x 素材对应约 14×14 逻辑像素；同一张图映射到浅半环面，各倍率按像素采样，无需绘制多角度素材
- 浅黄色圆盘半径为 3.25 逻辑像素，以适配素材中央开口；花瓣与圆盘使用共同深度缓冲，侧视时近侧花瓣可以遮住圆盘，花冠随身体定向并随注视方向倾斜
- 观察时使用短手电筒柔光，替换普通监视者的角锥线框；探出、缩回、避让、换位与观察事件继续沿用既有行为
- 在设置中主动切换为朋友？时，新建和已有槽位都会填入黑色，可继续修改颜色后统一保存；切回普通时，默认黑色改为白色，其他自定义颜色保留。重新打开设置保留已保存的配色，不自动重置。配置中省略槽位颜色时按外观补入默认色

轮廓和渐变定义位于 `rw_creature_pet/overseer/graphics/friend/body.py`，花冠曲面与圆盘投影位于 `rw_creature_pet/overseer/graphics/friend/head.py`，外观分派位于 `rw_creature_pet/overseer/graphics/render.py`

双触须参数位于 `rw_creature_pet/overseer/graphics/friend/filaments.py`：`LENGTHS`、`COLORS` 按短 / 长排列；`BASE_OFFSET` 为连接点沿颈部向身体退后的距离，`BASE_DEPTH` 为颈部背面连接点的深度；`BACK_ANGLES = (30., 55.)` 为两条触须从背面深度方向朝身体后方偏转的角度，增大时更靠近身体；`TURN_DEPTH_SOFTNESS` 控制极远侧视时换边的平缓程度；`GRADIENT_START` 和 `TIP_COLOR` 控制末端渐变。脸盘颜色在 `graphics/friend/head.py` 的 `DISC_COLOR`，修改后重启以刷新投影缓存

`CURVE_AMPLITUDES = (2.5, -3.0)` 分别控制短须 C 弧和长须 S 弧的侧向偏好幅度（逻辑像素，实际弯幅还受其他力影响），负值翻转对应弯曲方向；`CURVE_STRENGTH = .06` 控制恢复弧线的弹性力度，越大越容易维持形态，设为 0 关闭本次弯曲偏好

`SIDE_VISIBILITY_GAIN = 3.` 控制侧向可见性增强，设为 `1.` 恢复原投影，建议在 `2.`～`4.` 间调整；数值越大，越小的偏转就能明显向侧面展开，但正中附近的变化也越敏感。小于 1 按 1 处理。默认值下，原侧偏系数 `0.1 / 0.2 / 0.5` 约增强为 `0.29 / 0.52 / 0.87`；不改变头部和身体的朝向曲线

`python tools/overseer/review_friend_filaments.py` 生成侧向增强前后对照 `friend-filaments-side-visibility.png`、静止弧线前后对照 `friend-filaments-rest-curves.png`、四边明暗背景对照 `friend-filaments-four-edges.png`、连续转头预览 `friend-filaments-turn.png / .gif` 和转头、缩回、再探出动画 `friend-filaments-motion.gif`，输出到 `artifacts/overseer`

可直接调整 `graphics/friend/body.py` 顶部的 `ROOT_RADIUS`、`PEAK_RADIUS`、`NECK_RADIUS`（均为半宽）、`PEAK_FRACTION`、`NECK_FRACTION`、`GROWTH_POWER` 和 `NECK_LENGTH`；增大 `GROWTH_POWER` 会让主体前段更细长，`NECK_FRACTION` 需大于 `PEAK_FRACTION`

S 形姿态同样在 `graphics/friend/body.py` 顶部调节，沿用现有 40 Hz 时钟，不增加身体质点或物理约束循环：

| 参数 | 当前值 | 含义 |
| --- | --- | --- |
| `BODY_GAZE_FOLLOW` | 0.6 | 身体接收的注视影响，0～1；降低身体位移、颈部偏转及弯身响应，不削弱花冠转向 |
| `BEND_ROOT_AMPLITUDE` | 1.0 | 根段相对起终点连线的拱出幅度，逻辑像素 |
| `BEND_BODY_AMPLITUDE` | 2.0 | 主体在平滑连接曲线上的反弯幅度，逻辑像素 |
| `BEND_ROOT_FRACTION` | 0.5 | 根段所占参考弧长比例，支持 0.1～0.9，越小主体越早开始 |
| `ROOT_EXIT_ANGLE` | 18 | 根段相对起终点连线的额外出墙倾角上限，度 |
| `BEND_RESPONSE_SECONDS` | 0.65 | 接近新弯身目标的时间，秒，越大越迟缓 |
| `BEND_SIDE_SOFTNESS` | 0.25 | 侧视响应的柔和程度，越小越容易显出弯曲 |
| `BEND_LENGTH_REFERENCE` | 35 | 完整弯幅所需的出墙长度，较短时自动减弱 |

实际弯幅由侧视程度、出墙长度和探出程度共同衰减，不会持续保持表中的最大值。`ROOT_EXIT_ANGLE` 是上限，根侧幅度较小时，调高上限可能不会改变外形；设为 0 时根段沿起终点连线伸出，不额外拱起。`BEND_ROOT_FRACTION` 使用原参考曲线的弧长定位交界，不按固定的第几节截断

`BODY_GAZE_FOLLOW` 调小后，身体在持续观察时的位移和偏转都会变小，不只是跟随得更慢；设为 1 可恢复完整跟随，设为 0 则身体不再因注视目标而偏转，花冠仍会转向，探出和缩回仍照常执行。S 形响应包含柔和限幅，因此 0.6 表示输入影响系数，并非最终轮廓变化严格为原来的 60%；已有的弯幅、根段范围和出墙倾角仍可独立调整。普通监视者不使用此参数

头部倾角同样在 `graphics/friend/body.py` 顶部调整：`HEAD_GAZE_DISTANCE_FRACTION = 0.9` 表示鼠标与实际脸盘的横向距离达到工作区宽度的 90%，或纵向距离达到高度的 90% 时，达到原有最大倾角；斜向取两者较大值，不叠加距离而提前转满。使用当前工作区的逻辑宽高，随桌宠缩放、DPI 和工作区尺寸变化自动适配

近距离先较快轻仰，中段放缓，远端再逐渐转满，默认两段曲线在过渡点角度和斜率连续：

- `HEAD_GAZE_NEAR_FRACTION = 0.2`：近距离过渡点，占工作区宽/高的比例；调小后更早轻仰，设为 0 恢复此前的单段曲线
- `HEAD_GAZE_NEAR_ANGLE = 30.0`：过渡点的内部倾角，度；增大后近距离的轻仰更明显
- `HEAD_GAZE_POWER = 2.0`：过渡点之后的增长曲线，越大中段越缓；设为 1 时后半段线性增长，此时过渡点会有速度变化

以近距离角度 30° 为例，距离为 10%、20%、50%、75%、90% 跨度时，内部倾角约为 23°、30°、41°、67°、90°，最终花冠投影仍保留 `MIN_FACING` 的最小可见厚度。此曲线只用于花冠及观察光束，不重新调节身体的 `.6` 跟随响应，也不修改普通监视者的原有视线映射

预览脚本 `python tools/overseer/review_friend_bend.py` 会输出同一头部位置下的无弯曲／S 形对照、中心线和四边换向／缩回动画；`friend-gaze-comparison.png` 和 `friend-gaze-motion.gif` 对比完整身体跟随与当前系数下的鼠标注视姿态

花冠曲面可调整 `graphics/friend/head.py` 的 `TORUS_MAJOR_RADIUS`（环形截面的中心半径）、`TORUS_MINOR_RADIUS`（截面的径向半宽）和 `TORUS_HEIGHT`（向前拱起的高度，当前 1.75，设为 0 可比较平面效果）；圆盘半径由 `graphics/friend/body.py` 的 `DISC_RADIUS` 控制，`HEAD_OCCLUSION_RADIUS` 独立控制身体末段的遮挡余量

`adaptive` 模式会在 1x、1.5x、2x 等密度直接投影同一份素材，2x 保留原稿精度；`classic` 仍先生成 1x 像素再放大，因此细花瓣会更粗糙。修改 PNG 或曲面常量后需重启进程，以刷新素材及投影缓存

花冠仅在显示朋友？外观时加载素材和 NumPy，几何构造一次，最多缓存 128 个局部投影结果；不增加物理节点、计时器或鼠标命中范围。静止绘制继续复用监视者现有的整图缓存

可运行 `python tools/overseer/review_friend_head.py` 生成多角度、1x/1.5x/2x 预览和转头 GIF，并测量持续改变视角与缓存命中的投影耗时；此计时不含首次加载、仿真和系统窗口合成。`friend-head-near-curve.png` 对比横向和纵向不同工作区跨度下，单段平方曲线与新增近距离轻仰曲线的外观

### 朋友？观察光

## 局部绘制与性能

人偶和各只监视者分别由独立显示窗口保留绘制结果。监视者的变化从不加入人偶的更新矩形，两者分处屏幕两侧时也不会生成横跨桌面的联合矩形。监视者窗口固定覆盖本次根部周围的最大外形范围并裁到工作区，避免每帧移动/缩放窗口；退场直接隐藏窗口，由桌面合成器恢复下方内容。

所有监视者共用宿主 40 Hz 时钟，最多 30 Hz 绘制，不另开定时器。每步共用一次鼠标读取，同步选点时共用一份人偶外形；没有活动监视者且未尝试出现时不读取鼠标。关闭功能时不轮询鼠标、不跑外观仿真；等待/冷却仅更新倒计时，抽中出现时才读取鼠标和计算安全选点。临时避让隐藏时仍检查距离及事件期限，但不更新头部/触须物理。显示它不会改变 Oracle 的目标、行为、外观休眠标记或缓存版本。

## 探出、缩回和避让

一次预览包含 `隐藏 → 探出 → 观察 → 缩回 → 隐藏`。隐藏时事件仍保留；外观预览固定原位，计时事件则可以换位。
“显示 / 重置”是不计时的手动预览，直到清除或主动退场；随机事件使用下述独立计时。

- 鼠标进入根部 60 逻辑像素内，或人偶躯干中心进入根部 100 逻辑像素内，会触发缩回。人偶只使用两个躯干质点的中点作粗略检测，不计算碰撞外形，也不计机械臂、线缆、珍珠或光环。
- 完整避让缩回后，默认 **50%** 概率留在原位、**50%** 概率换到其他安全位置。同一次持续避让只抽签一次；没有其他安全位置时也留在原位，不反复抽签或逐帧重算候选。
- 新根部从当前允许活动边内随机选取，仍避开四角、鼠标、人偶外形及人偶安全圈；与旧根部保留至少两倍外形范围或鼠标安全距离的间隔。只有包括最后一个插值帧都完全不可见时才能换位，不绘制横跨屏幕的移动过程。
- 新位置也需连续安全 `safe_delay`（默认 0.45 秒）后探出。原位等待则要求鼠标距离至少 100、人偶距离至少 150 逻辑像素，并持续安全相同时长；两种威胁必须同时解除。
- 快速靠近又离开、还未完整缩回就安全时，保留原位连续反向探出。手动“缩回”、事件到期及关闭自动功能引起的退场不触发换位。换位不生成新事件、不重抽持续时间；隐藏等待照常消耗剩余时间，暂停仍冻结。

调试换位请用 **随机位置触发一次**；在 **事件设置…** 将换位概率设为 100% 可强制检查换位分支，设为 0% 可检查原位等待。保持鼠标靠近至完全隐藏，或把人偶移近。**显示 / 重置** 仍固定在指定位置，方便外观检查。

## 随机事件与设置入口

打开 **监视者调试… → 事件设置…**。默认关闭自动出现，以便先验证参数；手动触发不受此开关限制。

- 默认空闲时每 **30 秒**抽签一次，每次出现概率 **15%**。只有等待检查时抽签，正在显示、避让隐藏、退场和冷却期间均不重复抽签。启动或重新启用时先等待一个完整间隔。
- 出现时抽取 **20～45 秒**事件时长，包含探出和中途避让隐藏。到期即锁定退场；即使鼠标随后离开，也不再重新探出。等待末帧完全隐藏后，才结束本次事件。
- 完成退场后抽取 **60～120 秒**冷却，冷却结束再等待一个检查间隔。关闭自动出现会使当前计时事件平滑退场，随后不再产生新事件；不计时的手动外观预览仍可使用。
- 所有计时使用宿主的 40 Hz 仿真，跟随暂停冻结；单步推进 0.025 秒。暂停期间不会因系统时间经过而到期，也不会恢复后补发事件。
- 出现位置使用当前人偶允许活动的边缘。先扣除四角外形余量、鼠标安全距离和人偶头部/四肢/衣袍占用区间，再按剩余边缘长度随机选择位置。关闭调试避让也不会取消出现位置的鼠标避开检查。没有合法位置则跳过该次机会，在下次间隔重新抽签。
- 场景几何检查只在抽中、尝试出现或换位时执行；未出现和冷却期间不运行外观物理。活动期间人偶避让只增加简单距离检查，不唤醒人偶物理或重绘。

设置窗口的 **应用** 只修改本次调试；**重新读取事件参数** 从启动配置读取事件与避让参数，点击应用后生效，不覆盖主色预览。已抽取的事件/冷却剩余时间不因改范围而重置。禁用、启用和检查间隔变化立即遵循上述规则。
**保存配置副本…** 会保存包含当前监视者参数的完整 JSON 配置，保留其他启动配置字段。原 TOML 不会被覆盖。下次使用：

```powershell
python run_pet.py --creature oracle --debug --config "D:\path\overseer-settings.json"
```

直接调试的按钮：

- **随机位置触发一次**：跳过概率/冷却，使用安全选点和配置时长；开关关闭时也可使用。
- **到期 / 退场**：立刻将事件视为到期，检查平滑缩回、彻底清除和冷却。
- **立即抽签**：仅在自动功能已开启且正在等待检查时可用，仍遵守概率和安全选点。
- **结束冷却**：跳过剩余冷却，随后可立即抽签或等正常检查。
- **显示 / 重置 → 缩回 / 探出**：无时限预览，直接检查隐藏和重新出现；预览期间自动检查挂起。

快速验证循环：点击 **事件设置… → 填入快速循环参数 → 应用**，将变为每 1 秒必定出现、持续 4～6 秒、冷却 2～3 秒。如果之前在手动预览，先点击 **清除**。取消主窗口暂停，观察面板显示的计时、检查次数和事件次数；需要时点击“定位监视者”。将鼠标留在根部附近直到事件到期，可验证隐藏也正常结束。

- 默认鼠标进入根部 60 逻辑像素内时缩回；离开根部 100 逻辑像素，并连续安全 0.45 秒后才允许再次探出。距离以固定根部计算，身体回缩不会使安全判定反复变化。
- 两个阈值之间保持已经触发的避让；在安全阈值附近来回经过会重新计时。根部位置和大小不受这些状态变化影响。
- 避让独立于观察方式，固定目标和扫视模式下也生效。取消“鼠标 / 人偶靠近时缩回”可检查近距离眼部外观；若已经触发缩回，仍会经过安全等待再探出。
- **缩回** 让本次预览保持隐藏；**探出** 解除手动隐藏，但仍遵守鼠标避让。动作在下一次仿真步开始，暂停时可用 N 检查。
- 连续改变目标时保留 `extended` 及其速度；不会重置头部和触须。头部从墙内连续映射到原来的悬停位置，四条边共用同一套局部坐标逻辑。
- 原版 `ExtensionOfSegment` 的幂次用于各身体段的展开，眼部尺寸、偏移和柔光随 `extended` 变化；触须连接长度、阻尼和向身体收拢也由它驱动。完全隐藏时停止外观仿真和随机数更新，仅保留避让检测。

原版 `extended` 每 tick 改变 0.25，40 Hz 下约 0.1 秒。桌宠采用可反向的临界阻尼过渡，默认探出主动作约 0.5 秒、缩回约 0.25 秒，末段继续平滑收敛；没有原版的墙内路径，因此收回到根部后方的一小段隐藏区域。

## 配色与动作配置

### 展开镜片观察

桌面 **设置 → 监视者** 新增 **监视者观察概率** 和 **间隔时间**：默认每 12 秒检查一次，35% 概率展开眼前镜片；概率为 0 时关闭此行为。仅在完全探出、安全且有鼠标注视目标时计时；鼠标离开有效工作区、近距离避让或事件退场时中断观察并合拢。普通监视者每次观察持续 3～7 秒，朋友？为 8～16 秒（均含展开过程），约 0.75 秒合拢后，再开始一个完整检查间隔，不叠加触发、不延长监视者驻留时间。暂停仍冻结所有计时。

外观参考本机 `D:\CODES\CS\rw_src\OverseerGraphics.cs` 中的 `HologramMatrix`：两层多边形镜筒及外圈三角线框，按注视方向投影，两组旋转和各片独立形变；展开/合拢按 `holoLensUp` 每 tick 增减 1/30，身体缩回时仍压拢投影以限制局部绘制范围

镜片使用逐线闪断和局部像素遮罩替代 Unity 的 `Hologram` 着色器：

- 开关过渡时按信号完整度随机隐藏整条线，部分端点暂时回到投影中心；保留下来的线维持亮度，不再分组均匀淡出
- 仅在镜片图层应用连续噪声缺口和移动的水平扫描条纹；噪声按世界坐标取样，四边都保持屏幕水平方向，不随镜片转向旋转，也不会擦除下方眼球、身体或触须
- 闪断使用独立随机数，在 40 Hz 仿真步推进；重绘不抽签，暂停冻结噪声相位和闪断，完全合拢后不推进这些状态
- 首次绘制时用 Qt 调色板查表预计算 33 档完整度、3 种扫描相位的 96×96 遮罩，四只监视者共享约 3.5 MiB 图块；之后由 Qt 平铺合成，不逐帧用 Python 遍历像素，也不在首次观察时加载计算库
- 这是对原版信号破碎效果的近似，不要求额外游戏贴图，也暂不包含横向扰动

运行 `python tools/overseer/review_lens_effects.py` 可生成四边开关动画、合拢过程截图和四只监视者的离屏耗时，输出位于 `artifacts/overseer/lens-effects*`；该工具只读配置，不改变桌面当前状态

原作 `OverseerAI.LensUpdate` 会综合目标静止程度、兴趣、自身静止时间和随机偏好积累 `bringUpLens`，以 0.7/0.3 阈值控制展开/收起。桌宠使用以上两个设置控制随机事件，并继续跟随鼠标。形状和观察的随机数均与出现、换位、身体运动隔离，绘制本身不抽签。无监视者或完全隐藏时不更新镜片形变；活动时仍只重绘监视者的小窗口，不唤醒人偶物理。

快速检查：在 **监视者调试 → 事件设置…** 将观察概率设为 100%、间隔设为 1 秒，显示预览并选择固定目标或把鼠标移至远处。调试状态显示镜片展开程度和累计观察次数；靠近、移出场景或点击“缩回”检查合拢。外观预览也允许展开镜片，但依旧不自动换位。

项目 `config.toml` 可使用以下配置，旧文件缺少这一节时使用相同默认值；用户 JSON 配置也会保留这一节：

```toml
[overseer]
enabled = false
appearance_mode = 'random' # random / resident
slots = [
  { id = 1, color = '#ffffff', appearance = 'standard', size = 0.6, filament_count = 4 },
  { id = 2, color = '#ff557f', appearance = 'standard', size = 0.8, filament_count = 5 },
]
check_interval = 30.0
appearance_probability = 0.15
duration_min = 20.0
duration_max = 45.0
cooldown_min = 60.0
cooldown_max = 120.0
size = 0.6
withdraw_distance = 60.0
reemerge_distance = 100.0
puppet_withdraw_distance = 100.0
puppet_reemerge_distance = 150.0
relocation_probability = 0.5
observation_probability = 0.35
observation_interval = 12.0
safe_delay = 0.45
emerge_seconds = 0.5
withdraw_seconds = 0.25
```

距离单位为逻辑像素，随固定预览倍率显示；`reemerge_distance` 必须大于 `withdraw_distance`，人偶的对应安全距离也必须大于缩回距离。`relocation_probability` 范围为 0～1。
新增槽位缺省主色为白色 `#ffffff`；旧版单色配置仍按原值迁移，项目 TOML 保留自行调整的配色与体型
点击调试面板中的颜色按钮预览其他颜色，不重置当前动作、不写入文件；取消选色保留原色。
修改配置文件中对应 `slots` 条目的 `color` 后点击 **重新读取配色** 即可生效。事件和避让配置可从事件设置窗口读取；体型与伸缩动作时长在重启窗口后加载。

## 模块与参数

- `rw_creature_pet/overseer/config.py`：基础形态、配色、避让与伸缩参数和校验。
- `rw_creature_pet/overseer/group.py`：固定槽位身份、独立模型与事件、共享选点上下文和其他根部避让
- `rw_creature_pet/overseer/events.py`：不依赖 Qt 的事件计时、冷却、抽签和边缘安全选点；与外观随机数隔离。
- `rw_creature_pet/overseer/graphics/lens.py`：持续观察计时、独立随机数、镜片线框形状与视线投影。
- `rw_creature_pet/overseer/ui/desktop.py`：独立的穿透显示层、全局鼠标读取和局部像素缓存。
- `rw_creature_pet/oracle/ui/overseer.py`：两种宿主共用的工作区边缘与人偶外形避让范围。
- `rw_creature_pet/overseer/ui/settings.py`：事件设置、快速循环预设、配置重读与 JSON 副本保存。
- `rw_creature_pet/overseer/model.py`：不依赖 Qt 的 40 Hz 模型与伸缩状态。完全探出时头部到根部的最大距离为 `50 * size`，眼球绘制半径为 5；根部、悬停点、头部和注视目标分别保存。
- `rw_creature_pet/overseer/graphics/render.py`：局部像素缓存、十段曲线身体、眼球与瞳孔、数量可调的五节点柔性触须。复用主图集的 `Circle20` 和 `pixel`；无图集时使用几何图形占位。绘制不会推进模拟或消耗随机数。
- `rw_creature_pet/overseer/ui/debug.py`：独立调试面板。
- `rw_creature_pet/oracle/ui/debug_window.py`：调试宿主，提供坐标换算、时钟、鼠标位置和画布。

身体/眼部的结构、头部悬停与距离反应参考原版 `Overseer.cs`、`OverseerAI.cs`、`OverseerGraphics.cs`。
短触须采用少量节点的弹性链，柔光使用局部径向渐变，作为原版 `Mycelium` 与 Unity 着色器的轻量近似。
触须总静止长度按原版的节点数和减半后的连接间距换算，`size = 0.6` 时为 22.5 逻辑像素；以固定五节点重采样。
连接段采用双向长度约束，拉长时收紧、压短时撑开。中段受到较弱的姿态引导，末端自由摆动，不再被整条目标曲线拉短。
观察时触须沿头部视线前伸，使用 `t²` 权重让前向力从根部到末端逐渐增强；通过现有镜片展开量平滑加强与恢复，不重置节点或锁定末端
原版 `OverseerGraphics.Update` 的 `useDir * t² * 0.5` 持续存在，并不直接由 `holoLensUp` 开关控制；桌宠将普通外观的日常力度设为 `FILAMENT_IDLE_FORWARD = 0.05`，观察力度为 `FILAMENT_OBSERVE_FORWARD = 0.5`，两者位于 `overseer/model.py`
“朋友？”日常保持原 C/S 弧，观察时逐渐减弱后向引导和弧线偏好，使两条触须前伸；观察结束、避让或离场时平滑恢复。沿头部视线的二维投影施力，正视时减弱，四条边共用同一物理逻辑
运行 `python tools/overseer/review_filament_observation.py` 可在 `artifacts/overseer/filament-observation.png` 与同名 GIF 检查日常、前伸及恢复过程；只创建临时模型，不修改用户设置
展开半径在 `15～25 × size` 范围内缓慢变化，收缩时静止长度乘以 `extended`，完全隐藏后仍停止外观计算。
触须参考 `Mycelium.UpdateColor`：根部颜色先渐变为深青色，最后一段过渡到固定的纯蓝色尖端；渐变起点随体型由全长的 50% 提前到 30%（默认体型 0.6 时为 46%）。主色预览改变根部配色，末端蓝色保持原版设置。
监视者没有鼠标命中区域，不会扩大人偶的拖拽范围；调试与桌面使用相同模型和事件调度。

## 检查方法

建议依次检查四条边，分别将鼠标移到远处、贴近眼球、快速横穿根部左右两侧；观察眼睛是否连续转向、头部是否保持连接、触须是否平滑跟随。
在 1× 检查实际大小，用局部预览检查像素和遮挡。暂停后连续单步确认不会重复推进，调整窗口大小确认倍率保持不变。
再开启避让辅助圆，将鼠标保持在 60～100 的区间、在 100 附近往返、快速靠近后移远、重新探出时再次靠近，检查不会反复闪现，也不会瞬间换位置。

```powershell
python -m unittest discover -s tests/overseer -t . -v
python tools/overseer/review_overseer.py
python tools/overseer/review_lens.py
```

预览脚本使用本机游戏图集，在 `artifacts/overseer/` 生成四边的 1× 图片、放大对照、注视动画及调试窗口截图。
`emerge-withdraw.gif` 和 `extension-stages.png` 展示原位伸缩、滞回等待与重新探出。
`lens-four-edges.png`、`lens-observation.gif` 和 `lens-settings-*.png` 展示镜片视线投影、观察/避让过程及设置入口。
这些是 Qt 离屏渲染检查；鼠标手感仍应在实际窗口中复核。

多槽位离屏预览：`python tools/overseer/review_multiple.py`，输出 `artifacts/overseer/multiple-*.png`，包含中英文设置、小窗口及四只常驻监视者
