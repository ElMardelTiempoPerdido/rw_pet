## 当前可检查的内容

- 两个半径 6、质量 0.5 的身体质点，中心距离 9；零重力，40 Hz 固定步长，绘制使用前后帧插值。
- 指定位置的阻尼移动、减速停留、独立头部观察。身体倾角可在 −25°～25° 设置；移动方向不直接决定身体朝向。
- 沿四边圆角轨道滑动的底座，按实际弧长移动；带启动/停止滞回及反向等待。仍可切回固定底座模式。
- 绕过中央禁入区的分段 Bezier 漂浮路径；跨边通过相邻边的角落，接近目标和急弯时减速。
- 四个机械臂主关节、前三段的跨度区间约束、末端与人偶的定长连接、边缘边界约束。
- 本机原版图集中的头部、两侧耳壳、手脚、机械关节及主线节片，配合代码绘制的 Bell 耳侧刚性架与额头像素符号；前后遮挡随观察方向变化。
- 11×11 衣袍网格、独立手脚质点、七段曲线肢体、80 点主连接线和 14 束各 20 点的头部细线；起停、转弯时惯性跟随，静止后收敛。
- 一颗悬浮珍珠、原版字形投影；长停留、同边短途、低概率邻边移动、珍珠观察独立选择；自主侧倾与平滑回正。
- 移动目标、观察目标、珍珠悬浮点、可达范围、骨架和四倍局部检查窗。

当前默认开启四边滑动与曲线漂浮。为方便继续检查外观，调试窗口初始仍为手动模式；勾选“自主行为”后开始循环。加 `--desktop` 则在主屏工作区启动透明穿透桌宠，并默认开启自主行为。

## 阶段 7：桌面模式

```powershell
conda activate rw_pet
cd D:\CODES\PY\rw_creature_pet
python run_pet.py --creature oracle --desktop
```

默认 1×，一个场景单位对应一个屏幕物理像素，系统 125%／150%／200% 缩放不额外放大人偶。命令行可加 `--scale 1.5` 等倍率，运行中也可在托盘菜单调整。工作区太小或倍率太大时，实际倍率会自动降低，为既有导航保留至少 640×480 场景单位；提示文字显示实际采用的倍率。

桌宠覆盖主屏 `availableGeometry()` 工作区，避开任务栏占用区，支持工作区非零或负数原点。Qt 顶层窗口位置使用全局逻辑像素（DIP），场景尺寸为 `工作区逻辑尺寸 × DPR / 实际倍率`，绘制缩放为 `实际倍率 / DPR`。保持四边滑动底座，身体与机械臂使用原有可达走廊，珍珠保留边缘曲线路径；活动带比例沿用 `oracle.edge_fraction`，默认 20%。桌面场景不使用调试配置的固定宽高，也不采用调试专用的固定底座模式。`--activity` 仍只控制蜥蜴的平地／爬墙模式。

透明、置顶、不抢焦点和鼠标穿透采用与蜥蜴共用的 `configure_desktop_overlay`。宠物可见像素及透明区域都不接收鼠标，所有操作通过任务栏通知区的 Bell 图标提供；图标可能在折叠的通知区中。

| 托盘操作 | 效果 |
| --- | --- |
| 暂停／继续 | 同时冻结或恢复自主行为、珍珠、身体、机械臂和次级运动；不积压物理时间 |
| 大小 | 调整屏幕物理像素倍率，重新建立有效位置，保持暂停选择 |
| 打开调试窗口（或双击托盘图标） | 暂停并隐藏桌宠，打开现有独立 Oracle 调试场景，复用已加载图集及字形；关闭调试窗口返回原桌宠 |
| 重置到边缘 | 按配置的初始边和底座比例重置，重新开启自主行为；保留暂停选择 |
| 退出桌宠 | 关闭桌宠和其调试窗口，停止计时器并移除托盘图标，退出进程 |

调试窗口不与桌宠共享仿真时钟，预览操作不会改动隐藏桌宠的行为；关闭调试后恢复之前的暂停选择。在调试期间主动勾选暂停，返回后也保持暂停。调试配色依然是临时预览，需要持久化时修改 TOML；桌宠下次启动读取该配置。本次没有改写用户 TOML 或外观尺寸。

### 分辨率、DPI 和工作区变化

监听主屏切换、可用工作区、屏幕几何、DPI 以及窗口的 DPR 变化；短时间连续信号合并为一次更新。同尺寸/DPI 的工作区仅改变原点时，移动窗口并保留当前仿真。尺寸或倍率改变时，在底座当前所在边附近重建场景，保留其边内位置比例；身体、头颈、机械臂、衣袍和连接线一起初始化，前后帧位置一致，丢弃旧坐标系中的路径与速度。

珍珠悬浮点按旧工作区的相对位置映射，再投到新的人偶跟随矩形与当前边缘走廊的交集，珍珠回到该悬浮点并保留字形。正在进行的观察重新回到停留，保留自主开关、随机流及完成计数。暂停选择独立于场景，重建不会擅自继续运行。主屏暂时不存在或工作区为空时，隐藏桌宠并暂停；有效工作区恢复后重新建立位置。旧屏幕的信号连接会解除，退出时也会清理待执行的重建任务。

帧率与调试窗口一致：物理 40 Hz、主动绘制最高 30 Hz。复用人偶／线缆绘制缓存，珍珠独立绘制；静止无视觉变化或暂停时不主动重画画布。软线仍采用先前允许局部越界的方案，屏幕外沿由窗口裁剪。

## 操作

| 操作 | 结果 |
| --- | --- |
| 左键点击主场景 | 设置移动目标；红色为超出范围的请求位置，橙色为约束后的实际目标，停稳变绿 |
| 右键点击主场景 | 设置独立观察点；手动模式下不修改移动目标和底座，自主观察中则接管并停下 |
| 自主行为 | 循环停留／短途漂浮 → 注意珍珠 → 随机靠近或召近 → 保持观察 → 送回 → 停留 |
| 靠近观察一次 / 召近观察一次 | 关闭自主循环，直接开始对应分支；完成后停留，便于对照效果 |
| Shift + 左键点击主场景 | 接管自主行为，在人偶的跟随范围与当前走廊内设置悬浮点；远处点击会投影到有效范围，珠子平滑移过去 |
| 观察回正 | 结束自主观察，清除观察点并平滑回正；被召近的珠子自行送回 |
| 停止移动 / 结束观察并送回 | 接管自主行为，把当前位置设为停留目标，速度通过阻尼收敛；珍珠送回悬浮点 |
| 暂停（Space）/ 单步（N） | 冻结仿真 / 自动暂停并推进一个 tick |
| 重置（R） | 回到初始底座位置，重置人偶、机械臂、珍珠、路径、行为和计时，回到手动模式；保留暂停、倾角、滑动模式和预览颜色 |
| 初始底座 + 位置百分比 + 放置并重置 | 从指定边的位置重新开始；滑动模式会把角落位置投到真实圆角轨道 |
| 底座沿四边滑动 | 默认开启；切换会重置场景，关闭后可复测首批固定底座模式 |
| 顺时针 / 逆时针绕行一周 | 手动触发一条经过四角并返回起点的连续路径，到达后停下；不是自主巡游 |
| 显示规划曲线 | 虚线显示完整路线，小绿圈显示当前导引点；路线改变不重置身体或机械臂 |
| 骨架叠加 / 局部放大 | 查看质点与关节 / 四倍局部检查；放大镜为只读区域，不接收目标选择 |
| 预览比例 | 默认固定 1×，另可选固定 2×、4× 或适应窗口；固定倍率按屏幕像素计算 |
| 中键拖动 / 定位人偶 | 固定倍率下平移视图 / 将当前人偶置于视图中央，不移动或重置仿真 |

底座百分比在上下边从左到右、左右边从上到下计算。滑动模式可点击任意一边，路径会通过相邻边绕行；点击中央或屏外位置时，目标投到允许的活动区域。绿色为活动带，较亮的部分为给人偶外形和机械臂可达距离留出余量后的规划走廊。大工作区中，如果活动带深处超出任何底座位置的支撑范围，规划走廊会相应收窄。

固定底座模式仍将目标限制在当前边及底座的可达范围内。主视图默认固定 1×：一个游戏单位对应一个屏幕物理像素，窗口最大化、调整大小或系统 DPI 缩放不会放大人偶。固定 2×/4× 也遵守同一规则；四倍局部检查窗同步抵消系统 DPI 缩放。工具栏、字体等界面元素仍正常遵循系统缩放。

固定倍率下只改变视口范围；场景放不下时可中键平移，或点击“定位人偶”。选择固定倍率时会定位当前人偶，随后相机保持在该位置，不自动追踪；选择“适应窗口”可随时查看完整场景。所有操作只改变视图，不改变世界坐标、运动参数、目标、物理时钟或配色。左/右键取点使用同一套反向坐标变换；放大镜遮住需要点击的位置时，可暂时关闭“局部放大”。

## 阶段 6：一颗珍珠与日常观察

`oracle_behavior.py` 的小型状态机在 40 Hz 固定步长中推进，不读墙钟、不在绘制时抽随机数。身体停稳、姿态回正后先停留 3～6 秒，再独立选择一项活动，不再让每轮活动都必须以观察珍珠结束。允许跨边且不在冷却中时，默认选择概率如下：

| 活动 | 默认概率 | 表现 |
|---|---:|---|
| 继续停留 | 38% | 再休息 7.5～18 秒；可进入外观休眠 |
| 同边短途漂浮 | 33.25% | 在当前边内选择约 60～160 单位的偏移，受边界裁限后至少 30 单位 |
| 注意珍珠 | 23.75% | 注意约 0.9～1.5 秒，靠近或召近，保持观察 3.5～6 秒后送回 |
| 移到相邻边 | 5% | 只选择当前边的两条相邻边之一，最多经过共用的一个角 |

跨边目标位于新边靠共用角约 18%～38% 的区段；两个方向都可能被选中，但按路径长度更偏向较近的方向。路径明确经过这个角，不能改走另外三个角或选择对边。完成后至少 60 秒才允许再次随机跨边。固定底座、冷却期中的跨边选项退回长停留；其他活动不重抽签。

可在现有 `[oracle]` 配置表中添加 `cross_edge_probability = 0.05`，取值 0～1，设为 0 可关闭随机跨边。未填写时使用默认 5%，启动和本轮实现均不改写用户 TOML。剩余概率按停留 40%、同边短途 35%、珍珠 25% 分配。调试窗口的“短途漂浮一次”“移到邻边一次”会接管自主循环，运行一次后停止；邻边按钮不受随机概率或冷却限制，固定底座时禁用。

- **靠近**：参考 `SSOracleBehavior.investigateMarble` 的约 50 单位观察距离，在安全候选位置中优先选择接近当前位置的一个，规划一次身体曲线。自主模式仅选择当前边内、距身体不超过 200 单位的观察点；否则改为召近，防止观察行为绕过低概率跨边限制。手动“靠近观察一次”不额外限制身体跨边，但悬浮点也受跟随范围约束。靠近期间不让跟随逻辑抢走观察中的珠子，不加入抓取或手部动作。
- **召近**：参考 `inspectPearl` 的目标牵引结构，身体停在当前位置，珠子移动到脸侧约 38 单位处。目标点避开衣袍及中央禁区，抵达后才开始观察计时。
- **保持与送回**：观察目标每 tick 取珍珠的真实位置，头部沿用现有平滑独立观察；结束后送回当前悬浮点（可能已随人偶移动更新），躯干平滑回正，停稳后解除观察。人偶停在观察位置，再次独立选择日常活动。
- **手动接管**：点击移动／观察、绕行、关闭自主开关、停止等操作会结束当前自动流程；珠子平滑回到悬浮点，不瞬移，也不会在下一帧被 AI 抢回控制。暂停与单步同时作用于行为、珠子、身体和次级运动。模式切换与重置清除行为状态。

悬浮与牵引在 `oracle_pearl.py` 中独立实现。保留原作的“目标牵引 + 速度阻尼”结构，桌面适配增加收敛阻尼；珍珠沿已有 `EdgePlanner` 曲线推进，起停加减速，实际每段移动及插值仍受边缘约束。复用身体走廊的至少 36 单位边距，覆盖珠体和 15×15 字符；跨边召近与送回均绕过角落。固定底座模式的悬浮点也受当前边和可达范围限制。停止误差足够小时锁定悬浮点，静止后不持续抖动或强制重绘；没有额外周期性上下浮动。

行为不是原版剧情状态机的逐帧移植。目前没有加入房间剧情、珍珠矩阵、多珠调度、手持珍珠或 Unity 随机流复刻。调试重置使用固定且相互独立的行为／字形／眼睛随机种子，方便重复对照；同一颗珠子的字符不会在观察、送回或重绘时重新选择。行为时长、观察距离和短途距离集中在 `OracleBehavior` 类常量；珠子的速度、加速度集中在 `PearlState` 中。

### 珍珠随人偶迁移悬浮点

跟随矩形以人偶的上身质点为中心，默认宽 360、高 280 逻辑单位，保持屏幕水平／竖直方向，不随身体侧倾旋转。同边小范围活动时，悬浮点保持原位；超出矩形后，悬浮点向内收一段，珍珠再沿曲线追上。跨边时，悬浮点还必须与人偶处于同一条安全走廊，防止虽然距离较近，却隔着中央禁区的内角留在旧边。角落重叠区允许两条相邻走廊。

这是柔性跟随范围：虚拟悬浮点始终处于范围内；珍珠的实际位置在加速和绕角期间可以暂时落在框外，停稳后回到框内。不会瞬移、硬裁真实位置，也不会把整条珍珠路径变成穿过中央区的直线。观察期间可以更新虚拟悬浮点，但珍珠的实际目标由观察状态机控制；送回或手动取消时使用更新后的悬浮点。

在已有 `[oracle]` 表中可选添加以下字段；不填写时直接使用默认值，两项均至少为 160。它们随桌宠本身的缩放一起显示，不受调试窗口大小影响；本轮未改写用户 TOML。

```toml
pearl_follow_width = 360.0
pearl_follow_height = 280.0
```

`PearlState.FOLLOW_INSET = 64` 控制超距后内收的距离（不超过对应半边长的 40%），`REPLAN_TICKS = 12` 保证跟随路径最多每 0.3 秒重建一次。新路径继承速度和牵引前置距离；追赶速度上限为 2.4 单位/tick，普通召近和送回仍为 1.6。珍珠的过角点靠近安全走廊内角，保留 16 单位余量，避免为机械臂预留的走廊中线导致珠子先向外绕远；身体的路径规划参数不变。

跟随逻辑放在每颗 `PearlState` 中；当前场景仍只创建一颗珍珠。调试窗口开启“显示规划曲线”时显示灰色跟随矩形与悬浮点十字，桌面模式不绘制这些标记。静止后不重规划、不改珍珠修订号，也不唤醒人偶／衣袍／线缆缓存。工作区重建、手动悬浮点和重置均使用同一套范围约束。

### 自主躯干朝向

`oracle_pose.py` 的 `OraclePose` 独立计算躯干目标角。自主短途／邻边移动根据水平移动速度侧倾，最大附加目标约 20°；珍珠观察根据珠子所在方向侧倾约 16°，保持观察时逐渐放松至初始量的 60%。头部仍独立追踪珍珠的实际位置，不把躯干方向当成眼睛视线。

### Bell 默认闭眼

停留和短途漂浮默认闭眼。每次进入“注意珍珠”时，以 10% 概率睁眼，仅抽取一次，决定沿用到靠近／召近和保持观察结束；进入送回阶段或手动取消时闭合。因此闭着眼睛也会转头、靠近或召近珍珠，不把开眼作为行动的前提。手动指定观察点也使用同样概率，连续更新同一轮观察的位置不重复抽签，清除观察点后闭合。

## 阶段 4 的路径和支撑协调

路径规划把四边看作互相重叠的安全走廊，选择相邻角落连接，使用 Bezier 圆滑折角。同边移动也使用受限的曲线。每条曲线递归检查控制点凸包是否完整落在安全走廊内，不能仅检查起点和终点；身体实际移动的线段也检查中央区域，覆盖绘制插值。

身体中心预留至少 36 单位外形边距，覆盖头部附件、独立观察和倾斜时的衣袍与手脚。机械臂杆件也避开中央区域；跨角杆件采用角点外侧切线修正，避免把关节突然投到另一条边。小场景配长机械臂时允许更深折叠，保持关节连续。绘制不靠裁掉进入禁区的身体像素来隐藏越界。

底座轨道内缩 18 单位，圆角半径最大 32。轨道参数为实际弧长，矩形的长边和短边不会出现不同的线速度；底座法线随圆角连续变化，人偶仍保持自己的躯干姿态。底座追随路线前方的一小段，身体根据剩余支撑距离减速，必要时等待底座。

底座启动阈值为 `min(80, 可达半径 × 0.3)`，停止阈值为启动值的四分之一；目标沿轨道变化不超过 12 单位时不更新底座目标。一般要求方向稳定 20 tick 才启动或反向，接近支撑极限时允许提前启动。反向先减速，不直接翻转速度。

以下可选字段加在已有的 `[oracle]` 表内；旧配置不写这些字段也会使用默认值。本次实现没有改写用户的 TOML 或配色。

| 配置字段 | 默认值 | 作用 |
| --- | --- | --- |
| `sliding_base` | `true` | 启动时开启四边滑动；窗口内也可切换 |
| `float_speed` | `1.6` | 导引点最大速度，单位/tick；允许 0.3～2.0 |
| `base_speed` | `2.8` | 底座最大速度，单位/tick；允许 1.5～4.0 |

固定 40 Hz 下，默认速度上限分别相当于 64 和 112 单位/秒；实际速度会受起停、弯曲程度和支撑距离影响。导航代码在 `rw_creature_pet/oracle_navigation.py`，场景协调在 `oracle.py`。

### Bell 衣领与念珠

保留用户现有的衣袍上下渐变、袖根构造及袖口半宽 5，不需要衣袍花纹贴图。内搭直接为原有胸肩/躯干贴图和颈部线段着色，不再使用独立的固定多边形。颈部当前半宽为 1.5（全宽 3，沿用用户调整）；平领口位于头部中心沿实际颈部方向退回 6.5 的位置（比上一版下移 1 个逻辑像素），随头颈伸缩、偏转和渲染插值移动，胸肩覆盖与身体轮廓一致。领口以上保留皮肤色，不增加物理节点。

外袍 V 领通过裁掉真实衣袍覆盖范围实现，轮廓底色、内部网格和袖根都避开开口。浅色领边取两个 V 形范围的差集，与开口一起通过原有 11×11 布料三角形插值，因此跟随布料变形。`OracleRenderer.GOWN_NECK_HALF / GOWN_NECK_DEPTH` 控制开口，`GOWN_TRIM_HALF / GOWN_TRIM_DEPTH` 控制领边外缘，`INNER_NECK_HEAD_GAP / INNER_NECK_HALF` 控制高领距头部的距离和颈部半宽。衣袍物理和原有下垂参数不变。

当前 V 开口的 UV 半宽/深度为 0.38/0.28，较首版略加宽、变浅；浅色领边外缘为 0.70/0.44。相对开口的半宽差和深度差各增至首版四倍。领边两端沿衣袍边缘网格的方向延伸到袖根，再用“衣袍主体与左右袖子靠肩的前三分之一区域”的并集裁剪；浅色领边最后覆盖袖根接缝，并随袖子形状变化，不扩大肩部外轮廓。开口本身仍限于衣袍网格。静止正面几何测量中，V 夹角约 43.6°→50.1°，边线 30%/50%/70% 位置的法向宽度约 0.71/0.69/0.66→2.91/2.97/2.99 个逻辑像素。此前领边加宽时，相关 10 项衣领/念珠、缓存和真实图集活动区边界测试通过（28.274 秒）；观察及倾斜预览已更新。本轮未改写用户 TOML。

尺寸集中在 `render_oracle.py` 的 `OracleRenderer` 类常量中：`SLEEVE_ROOT_HALF_WIDTH=3`、`SLEEVE_CUFF_HALF_WIDTH=5`、`SLEEVE_ROOT_RISE=2`、`SLEEVE_SHOULDER_OUTSET=3`、`OPEN_EYE_WIDTH=2`、`OPEN_EYE_HEIGHT=2`。这些是本项目为 Bell 选择的设计值，不作为原作角色设定；没有新增 TOML 字段或改写用户配色。窗口的“恢复 Moon 默认色”仍然只恢复颜色。

袖根从上身中心向两侧各偏移 4，再沿身体朝头部方向上移 2；起始曲线控制点的横向外伸从原版 5 收至 3，让肩部外弧更靠近衣袍主体，形成自然溜肩。位置和曲线都使用身体局部方向，随倾斜旋转。袖口仍跟随原来的手部质点，半宽仍为 3→5。原版完好 Moon（DM）和 Pebbles（SS）没有袖根抬高，只有现时 Moon（SL）上移 3；这里是 Bell 的独立袖型选择。

袖子由七个曲线采样位置构造，每处包括沿段方向回退 0.3 倍距离的截面与当前截面；袖根使用向身体内侧回退 2 单位的参考点，保持原版 `MakeLongMesh` 的顶点和三角形衔接。半宽为 `3 + (5-3) * t² * (3-2t)`，避免平方根插值在肩部过早展开。手掌使用包含透明留白的原生 10×10 图集画布，可见部分约 4×4；先画手掌，再由袖口自然遮住靠手腕的部分。没有图集时使用直径 4 的圆形替代。

### 衣袍的动态下垂

`OracleAppearance.step_cloth` 参考 `OracleGraphics.Gown.Update`，保留原版基础宽度与轮廓：衣领固定，其余点只在偏离理想轮廓超过 `9×纵向进度` 时才被拉回。移除每帧追踪理想位置的恢复弹簧，恢复沿画面向下的视觉重力、0.02 的方向偏置，以及按原版顺序从四个相邻点传递的 0.05 连接力。两端都会访问同一条边；静态边长预先缓存，因为整体旋转和平移不会改变理想边长。

桌面没有房间重力状态机，暂用固定 `CLOTH_GRAVITY=0.45`，相当于原版 `0.9×room.gravity` 中的重力为 0.5。`CLOTH_DAMPING=0.90` 比原版 0.999 更快收敛。两者连同 `CLOTH_SLACK=9` 集中在 `oracle_appearance.py` 中，没有新增 TOML 字段。衣袍受力不反馈给身体、手部或机械臂，不改变导航。初始化先放到接近垂坠平衡的位置；从未下垂的轮廓释放也会由实际受力落到相同形态。

`ClothPoint` 分别保存积分速度和实际位移，以实际位移判断停止，休眠时保留积分状态。中线靠上的点可能产生近乎反向的方向插值，这种退化情况使用确定的旋转方向，避免微小浮点误差在 ±π 之间切换，引发停稳后衣袍中部细抖。

所有布点相对上身的距离上限约为 `24.3+9=33.3`，仍落在既有至少 36 单位的外形预留范围内；无需缩减下垂、扩大活动带或裁掉越界部分。三角形和绘制插值也保留这项包围半径。四倍局部检查窗增高到 250×290 并调整居中，完整容纳下摆。
