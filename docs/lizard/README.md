# WhiteLizard 桌宠

当前完成白蜥蜴外观、平地步态与转身：从本机游戏加载原版图集，绘制身体网格、五层头部、四肢与五节动态尾巴。启动后自动向右行走，到边界停步；反向先转身。品种外观数值采用原版 WhiteLizard 配置，个体随机倍率暂固定为 1。可开启骨架叠加检查物理，或关闭四肢复测身体落地。

原项目 README 的使用部分；运动细节和阶段记录见 [实现说明](movement.md)。

## 运行

```powershell
conda activate rw_pet
cd D:\CODES\PY\rw_creature_pet
python -m pip install -e .
python run_pet.py
```

本机也可以直接运行：

```powershell
& D:\Anaconda3\envs\rw_pet\python.exe D:\CODES\PY\rw_creature_pet\run_pet.py --config D:\CODES\PY\rw_creature_pet\config.toml
```

`config.toml` 保存默认游戏路径及调试场景尺寸。无配置文件时使用内置默认值；显式指定的配置不存在或不合法会报错。首次启动从 `RainWorld_Data/resources.assets` 提取主图集，缓存到 `%LOCALAPPDATA%/rw_creature_pet/atlases/<源文件标识>/`；后续启动复用缓存，游戏文件更新后使用新缓存。不会修改游戏文件，也不把游戏资源复制进源码仓库。图集加载失败会显示具体原因并回退到骨架视图。

## 操作

背景抓附调试：勾选“背景抓附场景”，输入身体中心的“离地高度”，点击“放置并重置”。进入该模式时自动开启骨架叠加；四足在背景建立固定抓点，身体保持当前位置。取消“启用背景抓附”后，身体保留当前状态并自然下落；再次勾选则尝试在当前位置重新抓附。暂停状态下可以用单步检查释放后的重力加速。切回平地场景会重置身体并恢复之前的步行设置。

离地高度范围为 8～floor_y-8，保证半径为 8 的身体位于有效背景内；它不是屏幕 y 坐标。编辑数值不会立即移动身体，只有点击“放置并重置”才生效。背景模式使用独立的八方向按钮和“停止”；也可输入任意角度后点击“按角度爬行”（0° 向右、90° 向下、180° 向左、270° 向上）。方向归一化后按慢行意愿与抓地反馈推进，斜向不会额外加速。先调整朝向，再沿指定直线推进；停止后完成已开始的落脚并收敛到静止姿态。

平地的左/右/步行支撑控件在背景模式停用。水平速度干预仍可用于测试弹性恢复。关闭抓附、重新抓附或重置会清除背景移动指令；失附时需重新关闭/开启抓附，不会自动凭空恢复。到边界会整条指令停步，不沿边界自动滑行；可选择相反方向离开。身体中心预留 37 单位边距供头部和调整朝向使用，建议从背景中部测试运动。

背景抓附时，点击画面设置身体中心的追踪目标；可以在途中再次点击更换目标。橙色十字表示目标，绿色表示已到达；点击坐标自动限制在安全区域内。跟随放大和完整视图都使用同一坐标转换。方向按钮、按角度爬行或停止会取消目标追踪，关闭抓附与重置也会清除目标。暂停时可设置目标，恢复或单步后才推进。

- 暂停/继续：按钮或 Space。暂停时不积累待补帧时间。
- 单步：按钮或 N，自动暂停并且精确推进一个 tick。
- 重置：按钮或 R，复位身体、四足和时钟，保留暂停、四肢开关及步行方向。
- 向左 / 停止步行 / 向右：按“慢行 / 积极移动”档持续移动，默认慢行；切换档位即时平滑生效，停止时切换不会自行出发。反向时先减速，转身后继续行走。停止后减速并完成当前落脚；如果已经开始转身，则先完成该次转身再站立。转身中再次改向会在当前转身完成后执行最新方向。运动按钮会开启四肢支撑。到边界停步后可用相反方向转身离开。
- 启用四肢支撑：关闭后恢复纯身体重力与碰撞；重新开启可恢复抓地。
- 跟随放大：默认开启，放大两倍并跟随身体，便于观察换步；关闭查看完整场景。
- 水平速度：输入 -3～3 逻辑单位/tick，再点击“施加水平速度”。这是一次性外力调试，保留竖直速度；四肢开启时随后会重新调整到步行目标速度。
- 骨架叠加：在游戏外观上显示身体连接、四足状态及物理质点；绿色质点表示身体触地，绿色脚表示抓地。白色短线标示头部朝向。速度向量、地面投影在骨架叠加下可独立开关，投影是参考点。背景网格可独立开关。

输入框聚焦时优先使用按钮。窗口缩放只改变视图比例，不改变逻辑场景尺寸。前后状态插值仅用于绘制，数值表始终显示最新 tick。

## 桌面模式

在 `rw_pet` 环境中运行：

```powershell
python run_pet.py --desktop
# 启动即四边巡游，并放大到 2 倍
python run_pet.py --desktop --activity wall --scale 2
```

不加 `--desktop` 仍打开原调试窗口。桌面模式为透明置顶窗口，不抢焦点，宠物及空白区域均鼠标穿透；使用任务栏通知区白色蜥蜴图标的右键菜单切换“底部行走 / 四边爬墙”、调整大小、暂停或退出。图标可能位于系统折叠的通知区中。图集或托盘不可用时会明确报告启动失败。

底部行走以主屏幕可用工作区下沿为地板，避开任务栏，抵达两端后转身往返。四边爬墙沿工作区边缘巡游，抓点和身体限制在上下左右各约 20% 形成的边缘区域内，沿相邻角点行进，不走穿过中央的捷径。此阶段活动模式由托盘选择，不自动在地面和墙面间翻滚切换；切换模式或大小会重新放置宠物。

坐标使用 Qt 的屏幕逻辑坐标：世界坐标乘宠物大小倍率后映射到工作区局部坐标，工作区原点由窗口位置处理，系统 DPI 缩放由 Qt 完成，避免重复乘缩放比例。默认 1 倍，可使用 `--scale 0.5～4`；小工作区会降低实际倍率，为身体和转向留足空间。主屏幕或工作区变化时重建场景，避免停留在旧地板或屏外。此阶段仅支持主屏幕，不跨多屏漫游。

验证：两种工作区尺寸各 12000 tick 的底部/墙面巡游；边缘抓点、完整四边路径、底部往返及体型回归。Windows 本机原生窗口检查确认 WS_EX_TRANSPARENT、WS_EX_NOACTIVATE、WS_EX_LAYERED，透明像素 alpha=0，系统命中测试透过窗口到达下方按钮；实际鼠标点击宠物可见身体位置，下方测试按钮收到点击。多种工作区尺寸及宠物倍率的坐标数值已检查，实际本机显示比例为 100%，其他系统缩放比例仍需实机验证。

## 平地停留姿态与观察调试

在调试窗口保留“启用四肢支撑”，点击“停止步行”，通过“停留姿态”选择“低伏休息 / 平身站立 / 抬胸观察”。调试界面默认低伏：前后身一起降低，腹部保留约 1.5 逻辑单位间隙。抬胸时后身维持低位，前身仰角可在 0～22° 连续调整，默认 16°；中间身体跟随同一倾角，避免腹部折角。角度与高度均平滑过渡，支撑脚保持世界坐标，恢复行走时逐渐退出休息姿态。22° 上限为当前腿长保留抓地余量；这些是桌宠适配参数，非原版固定角度。

右键指定独立观察点，蓝色标记显示目标，持续 10 秒；“清除观察”提前结束并恢复自动观察。观察不会设置移动目标或强迫身体转身，背后目标受颈部回正与角度限制。平地观察点与身体停留姿态可组合，但尚未按观察高度自动抬胸。暂停冻结观察计时，单步推进；重置清除指定观察点并重置自动观察序列，界面姿态选择保留。背景观察适配见下文。桌面模式也会自动张望，窗口保持鼠标穿透；尚未接入窗口切换等外部事件。

抬胸尾巴落地稳定性修正：尾节采用四个子步并统一位置与速度的约束结果，消除刚度残留速度与地板反复冲突；显示宽度使用约束后的长度。测试覆盖左右朝向抬胸长时间静置、尾节长度与不穿地、恢复行走及连续转弯。尾巴阻尼与跟随节奏有相应变化，属于桌宠适配。

平地肩颈使用共享切线的连续网格，颈部向身体逐渐增粗，去除肩腹部的圆形连接补片；只在尾根保留封口。头部仍使用原版图集、尺寸与独立观察连接，四肢仍根据实际髋部和抓点选帧。背景外观沿用此前的网格与遮挡顺序。对照截图：`artifacts/rest-postures.png`（左右朝向、低伏、站立、不同抬胸角度及低伏观察）。
