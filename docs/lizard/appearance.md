# 白蜥蜴外观：来源与实现范围

本阶段使用本机游戏主图集和 WhiteLizard 品种参数，接入已经验证的平地步态、转身与背景爬行。没有接入原版 Room、AI、调色板光照、变色或吐舌。图集是组合用的部件，不是一套预制行走动画。

## 图集读取

UnityPy 读取 `resources.assets` 中名为 `rainWorld` 的 Texture2D / TextAsset。缓存键包含资源文件绝对路径、大小和纳秒修改时间。先在临时目录完成提取和 JSON 校验，再公布缓存文件。图像仅从本机游戏提取；源码项目不附带资源。

帧按 frame 矩形裁切；支持 rotated，按 sourceSize 与 spriteSourceSize 还原透明原始画布，确保锚点不会因透明边裁切而偏移。原图和着色图分开缓存。读取失败或缺少所需帧时，界面明确显示原因并使用骨架调试视图。

## 绘制与模拟

背景身体使用四段、16 顶点、8 三角形的白色网格，加原版 Circle20 修整连接处。平地身体使用三段三次曲线采样的连续网格，共享节点切线和两侧边缘；颈部半宽 5、前身半宽 6.5、腹部和后身半宽 8，身体宽度仍应用当前 fatness。仅尾根保留 Circle20 封口，避免抬胸时肩部圆补片鼓出。这是侧视外观适配，并非原版网格逐句移植。尾巴为 19 顶点、17 三角形的连续网格，尾端收为一点；形状使用原版的分段宽度、拉伸半径与距离 / 5 的连接平滑规则。原版这些网格使用纯白 Futile_White，Qt 以白色填充三角形实现同一着色用途。

头部由下颌、下齿、上齿、头壳、眼睛五层组合，使用闭嘴姿态；平地按朝向选择 0～3 视角帧；趴墙固定使用背视帧 3，平面转向只改变旋转角，不切换帧或镜像。四肢使用 LizardArm 图集按距离选帧。原版未伪装白蜥蜴的 ArmColor 叠层透明度为零，因此不绘制该层。平地和趴墙均将一侧肢体先于身体、另一侧肢体后于身体绘制，允许近身腿段覆盖身体表面；趴墙仍先画尾巴再画身体，遮住尾根。四肢沿用真实抓点及迈步轨迹，不为绘图挪动支撑脚。图像采用最近邻采样。

头尾状态随固定 tick 更新，绘制只做插值，不修改模拟；暂停恢复同步其前后状态，重置重新构造。尾巴保留原版尺寸、800×0.1^i 的刚度衰减及尾端重力。为修复抬胸落地后的持续振荡，当前每 tick 分四步积分：先施力并移动，再从尾根向尾端投影地面和最大长度约束，速度由约束后的实际位移重新计算。没有继续叠加旧版 0.4 前节速度反馈；加入按时间步换算的接触摩擦与空气阻尼（每 tick 保留 0.85 / 0.9）。显示宽度也取约束后的长度。这是桌宠稳定化求解，不是原版 TailSegment 逐句移植。

## 当前简化

- 头部跟随采用阻尼目标控制；未逐句移植原版注视目标、呼吸、声音、威吓与张嘴控制。
- 背景身体半节方向采用归一化线性插值；平地采用连续肩颈曲线，未实现原版三维 Slerp、纵深转动及呼吸增粗。
- 四肢由现有平地或背景步态驱动；外观沿用原版图集尺寸，但不意味着步态已是原版逐帧复刻。
- 平地尾巴地形包含地板和侧边界；抓附时头尾另受背景活动范围约束，尾巴不受屏幕向下的重力。没有水流、房间瓦片或身体自碰撞。头尾不向身体施力。
- 白色为原版未伪装基色；眼和牙使用中性深色 #141414 代替房间 palette.blackColor。已加入日常头部脉动和独立展示变色；尚未应用房间光照与背景拟态。
- 脚趾像素可能超出原版 Limb 抓点，绘制裁切于地板避免穿地；不改实际抓点。
- 平地转身采用二维抬前身方案，背景使用连续转向。背景模式（包括关闭抓附后的下落）保持背视；没有实现地面与墙面之间的纵深翻滚过渡。

## 验证

`python -m unittest discover -s tests -t . -v` 包含裁切偏移、透明着色、缓存命中、缺图提示、原版参数与网格拓扑、反复转身时头尾稳定、渲染只读和原有物理/步态测试。本机游戏可用时直接验证真实图集；没有本机游戏时该项会明确跳过。

## 颜色脉动与展示

`rw_creature_pet/lizard/color_effects.py` 独立维护相位、兴奋度、闪白/眩晕计数、展示强度与色相。参考 `LizardGraphics.cs` 的 HeadColor、Stun、WhiteFlicker 与 showDominance 分支；头部使用白/暗两端的正弦幂函数，展示色同时混入两端及身体颜色。眼与牙仍为中性暗色。效果仅在固定 tick 更新，绘制只读取插值颜色。

当前适配：兴奋度由调试控件设定，默认 0.2；闪白按 tick 隔次切换；眩晕只模拟随机头色，不冻结身体；展示结束回白，不进入背景取色分支。没有声音/扑击头色覆盖、受击抖动或环境光源。独立随机序列用于调试，不是原版 Unity RNG。临时效果在重置时清除。

## 平地腿形修正

平地每条腿独立计算脚相对身体局部轴线的有符号侧别，按原版 0.3 系数平滑更新 flip；前后连接方向与 Unity/Qt 的 y 轴差异统一处理。同一对脚都位于身体下方时使用一致弯向，身体转向或脚跨过轴线时，按 abs(flip) 经过 +18 / +9 / +0 三组帧，符号用于贴图镜像。近远侧绘制顺序仍由身体侧别决定，不与 flip 绑定。

flip 在固定 tick 更新，绘制只插值，暂停同步前后值；轴线退化或脚恰在线上时保留当前符号，避免微小数值导致翻转。趴墙腿部也使用动态 flip，不再固定第三组形态；固定背视仅约束头部视角。动态腿形与分层允许上半段腿露出，并保留身体整体旋转时一致的背部朝向。

## 趴墙观察

观察目标沿用独立头部控制。BackgroundGrip 在移动 targets 之外维护 pose_targets，以当前前身局部轴线计算目标夹角，取 0.2 倍并限制到 ±0.18 rad；每 tick 以 0.06 平滑趋近，只在抓附且停止移动时驱动躯干弯曲。前身围绕中间质点旋转，保留连接长度和后身支撑；角度不累积到移动朝向。边缘和支撑腿余量不足时收窄偏转。抓附尾巴取消全局竖直重力，头尾位置约束使用世界提供的 background_position；平地求解保持原逻辑。头部深度帧和镜像继续固定为背视，不受观察夹角影响。
