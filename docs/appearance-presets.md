# 外观配置的导入与导出

在 **设置 → 角色设置** 使用“导入外观到当前角色设置…”与“导出当前角色的外观…”，具体参数在后方的 **外观细节** 页调整

## 保存和分享外观

1. 调整当前 Bell 或自定义迭代器的外观
2. 点击“导出当前角色的外观…”，选择“另存为新文件”或“更新已有文件”，填写名称
3. 将生成的整个文件夹发给别人，包含 `appearance.json` 和引用贴图的 `images` 目录；可以先压缩整个文件夹

导出读取当前表单，包括尚未保存的外观修改；导出内容成为新文件的默认值，不携带个人调整历史。使用角色设置时，单独导出外观不会解除当前角色关联

附加外观的选择与每个部件的显示、位移、对称复制、色相／饱和度／明度也会随外观保存，未启用的部件仍保留参数。女仆套装使用程序自带素材，不需要重复复制贴图

默认目录：

- 打包版：`BellPet.exe` 所在目录下的 `presets/appearances`
- 源码版：工程根目录下的 `presets/appearances`

目录不依赖启动时的工作目录，也不会落在单文件 EXE 的临时解压目录内；首次导入或导出时创建

```text
BellPet.exe
presets/
  appearances/
    appearance-我的迭代器-唯一目录后缀/
      appearance.json
      images/
        图片内容摘要.png
```

没有引用贴图时不需要 `images` 目录；引用同一张图的多个部件共用一份副本

## 导入与切换

- 解压收到的外观配置后，可点击“导入外观到当前角色设置…”并通过“从文件选择…”选择其中的 `appearance.json`，确认导入后，程序会复制配置和所有引用贴图至本机外观目录
- 也可以直接将整个文件夹放到 `presets/appearances` 中，打开外观导入窗口后下拉选择，并点击“导入”；支持子文件夹，清单文件需保持名为 `appearance.json`
- 自动保存默认开启，确认导入后保存并应用；仅浏览候选或取消弹窗不改变当前角色；关闭自动保存时先作为草稿，可点击“保存当前调整”或底部保存按钮
- 自动保存开启时，关闭窗口会先保存待处理的调整；关闭自动保存时丢弃未保存草稿，已导入或导出的文件夹仍然保留

载入时贴图还会复制到用户配置目录的 `appearance/images` 缓存，因此成功保存后，移动、删除共享外观文件夹不会破坏当前外观

外观载入的是一份独立副本，不会在启动时自动跟随共享文件的后续修改。来源和个人调整随当前角色保存，重新打开设置仍保持当前角色身份

## 个人调整与切换保护

外观文件中的参数是只读默认值，日常微调保存在本机，不会自动改写分享文件。每次导入读取外观文件内容，后续调整属于当前角色；要恢复此前调整过的版本，请使用该角色的外观历史

外观细节页显示“正在调整：名称”；导入外观只替换该角色中的副本，后续调整不影响独立外观库

整体替换前自动保留外观快照，可用“恢复切换前外观”或“最近外观…”选回，最多保留 10 份且不重复记录相同内容。普通参数微调不会逐次产生快照，恢复历史也只影响外观

“恢复默认外观”读取当前角色设置原本提供的外观默认值，与恢复最近一次自定义外观不同；右键参数可单项恢复。完整规则见 [个人调整与外观历史](personal-adjustments.md)

## 导出范围

按 [字段归属登记](preset-field-scopes.md) 选择 `appearance` 字段，包含：

- 当前主体类型及其配色：Bell 导出 Bell 配色，自定义导出自定义配色和形态参数
- 附加外观（常规 / 女仆套装）
- 自定义头身尺寸、双眼、面部贴图、耳机、内搭、高领、领口和领边，以及两个柔性部件的完整参数与图层
- 珍珠配色、投影颜色和珍珠播放光晕颜色，即使它们也在其他页签提供修改入口

参数会完整保存，包括默认值和关闭的部件；只要配置中有 PNG 引用，关闭的部件也会带上贴图。缺失或损坏的引用必须先修复或移除再导出

另一主体的配置、机械臂缩放、显示倍率、游戏目录、语音设置、光环和电弧开关、移动及珍珠行为均不随外观导出或覆盖

同版本中缺失的外观字段以代码定义的默认值补齐，不沿用上一位角色的参数或用户改过的默认 TOML；当前版本之外的外观文件会提示版本不匹配，未知或非外观字段会被拒绝

## 重复配置与版本

- 由 `id` 判断是否同一份外观，名称相同但 ID 不同的外观会同时出现在列表中，可通过选项提示查看路径
- 同一 ID 的多个文件按 JSON 中 `updated_at` 的时间选择最新有效版本，系统文件修改日期不参与排序
- 时间相同时按路径稳定排序；损坏的新版本不会盖过有效的旧版本
- 外观导入窗口以小红字列出重复文件的路径，最新有效版本列在第一项；程序不会自动删除重复文件
- 刷新发现新版或来源已删除时，保留当前草稿和来源，必要时额外显示“已载入版本”；明确选择候选后才载入，不把列表刷新当作切换
- 导入旧副本时仍载入库内同 ID 的最新有效版本，并显示重复路径
- “另存为新文件”始终生成新 ID 和新目录
- “更新已有文件”默认选中当前来源，也可选择其他外观文件，显示目标路径；保留目标 ID 并更新其原目录，不产生新的重复目录，不修改同 ID 的其他副本
- 目标在选择后被外部修改时，更新会拒绝覆盖，需刷新后重新选择

另存采用临时目录准备全部资源，校验完成后再整体改名。更新先准备新资源，最后原子替换清单；旧清单保留为 `appearance.json.bak`，旧资源保留供恢复使用。准备或替换失败时不改变原清单

## 文件格式与实现

`appearance.json` 使用 UTF-8 JSON，顶层字段为：

| 字段 | 含义 |
| --- | --- |
| `type` | 固定为 `rw-creature-pet.appearance`，区别于本机设置和角色设置 |
| `version` | 当前格式版本 `1` |
| `id` | 规范形式的 UUID，表示外观身份 |
| `name` | 1～80 字符的显示名称 |
| `updated_at` | 含时区的 ISO 时间戳；程序导出时使用 UTC |
| `config` | 保持配置原有的嵌套结构，仅包含当前主体对应的外观字段 |

PNG 引用只允许包内相对路径，不允许绝对路径、父目录跳转或链接逃逸；仅支持静态 PNG，每个文件不超过 1 MB；面部及耳机贴图最大 32×32 像素，柔性部件贴图最大 128×128 像素

代码分工：

- `presets/appearance.py`：格式校验、字段过滤、缺省值与外观应用
- `presets/library.py`：目录、导入导出、扫描和重复版本选择
- `presets/common.py`：外观和角色设置共用的元数据、路径、扫描与目录写入
- `oracle/ui/appearance_presets.py`、`oracle/ui/preset_panel.py`：选择与文件操作入口
- `oracle/ui/settings.py`：接入现有草稿、预览、保存和精度保留流程

需要一并分享行为参数时，使用 [角色设置](profile-presets.md)；其中携带一份独立的外观副本，不自动跟随此库更新
