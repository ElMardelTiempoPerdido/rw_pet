# 外观预设的导入与导出

在 **设置 → 外观** 顶部使用“外观预设”下拉框、“导入外观…”、“导出外观…”和“打开预设目录”

## 保存和分享外观

1. 调整当前 Bell 或自定义迭代器的外观
2. 点击“导出外观…”，填写名称
3. 将生成的整个文件夹发给别人，包含 `appearance.json` 和引用贴图的 `images` 目录；可以先压缩整个文件夹

导出读取当前表单，包括尚未保存的外观修改；不会顺便保存游戏路径或其他设置，也不会直接改变运行中的人偶

默认目录：

- 打包版：`BellPet.exe` 所在目录下的 `presets/appearances`
- 源码版：工程根目录下的 `presets/appearances`

目录不依赖启动时的工作目录，也不会落在单文件 EXE 的临时解压目录内；首次导出或点击“打开预设目录”时创建

```text
BellPet.exe
presets/
  appearances/
    appearance-我的迭代器-唯一目录后缀/
      appearance.json
      images/
        图片内容摘要.png
```

没有引用贴图时不需要 `images` 目录；引用同一张图的多个部件共用一份副本

## 导入与切换

- 解压收到的预设后，可点击“导入外观…”并选择其中的 `appearance.json`，程序会复制配置和所有引用贴图至本机预设目录
- 也可以直接将整个文件夹放到 `presets/appearances` 中，点击“刷新”后下拉选择；支持子文件夹，清单文件需保持名为 `appearance.json`
- 选择后先填入设置表单，可以继续微调、打开面部预览；点击“保存并应用”或“保存并关闭”才让桌宠使用这份外观
- 取消设置不会保存本次外观选择；已导入或导出的文件夹仍然保留

载入时贴图还会复制到用户配置目录的 `appearance/images` 缓存，因此成功保存后，移动、删除共享预设文件夹不会破坏当前外观

预设载入的是一份独立副本，不会在启动时自动跟随共享文件的后续修改；重新打开设置时显示“当前外观（不关联预设）”，实际外观参数从已保存的用户配置读取

## 导出范围

按 [字段归属登记](preset-field-scopes.md) 选择 `appearance` 字段，包含：

- 当前主体类型及其配色：Bell 导出 Bell 配色，自定义导出自定义配色和形态参数
- 附加外观（常规 / 女仆套装）
- 自定义头身尺寸、双眼、面部贴图、耳机、内搭、高领、领口和领边
- 珍珠配色、投影颜色和珍珠播放光晕颜色，即使它们也在其他页签提供修改入口

参数会完整保存，包括默认值和关闭的部件；只要配置中有 PNG 引用，关闭的部件也会带上贴图。缺失或损坏的引用必须先修复或移除再导出

另一主体的配置、机械臂缩放、显示倍率、游戏目录、语音设置、光环和电弧开关、移动及珍珠行为均不随外观导出或覆盖

同版本中缺失的外观字段以代码定义的默认值补齐，不沿用上一位角色的参数或用户改过的默认 TOML；当前版本之外的预设会提示版本不匹配，未知或非外观字段会被拒绝

## 重复配置与版本

- 由 `id` 判断是否同一份外观，名称相同但 ID 不同的预设会同时出现在列表中，可通过选项提示查看路径
- 同一 ID 的多个文件按 JSON 中 `updated_at` 的时间选择最新有效版本，系统文件修改日期不参与排序
- 时间相同时按路径稳定排序；损坏的新版本不会盖过有效的旧版本
- 外观页以小红字列出重复文件的路径，当前采用的版本列在第一项；程序不会自动删除重复文件
- 从列表选择一份外观后再导出，会保留它的 ID 并生成新日期的新版本目录，原目录不被覆盖
- 要创建独立外观，可先将下拉框切到“当前外观（不关联预设）”，当前参数不会改变，之后导出会生成新 ID

导出采用临时目录准备全部资源，校验完成后再整体改名为最终目录；失败不会留下可被列表误选的半成品，也不会覆盖已有预设

## 文件格式与实现

`appearance.json` 使用 UTF-8 JSON，顶层字段为：

| 字段 | 含义 |
| --- | --- |
| `type` | 固定为 `rw-creature-pet.appearance`，区别于本机设置和未来的完整预设 |
| `version` | 当前格式版本 `1` |
| `id` | 规范形式的 UUID，表示预设身份 |
| `name` | 1～80 字符的显示名称 |
| `updated_at` | 含时区的 ISO 时间戳；程序导出时使用 UTC |
| `config` | 保持配置原有的嵌套结构，仅包含当前主体对应的外观字段 |

PNG 引用只允许包内相对路径，不允许绝对路径、父目录跳转或链接逃逸；沿用面部 PNG 的静态图片、最大 32×32 像素和最大 1 MB 限制

代码分工：

- `presets/appearance.py`：格式校验、字段过滤、缺省值与外观应用
- `presets/library.py`：目录、导入导出、扫描和重复版本选择
- `oracle/ui/appearance_presets.py`：选择与文件操作入口
- `oracle/ui/settings.py`：接入现有草稿、预览、保存和精度保留流程
